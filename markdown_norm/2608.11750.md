## Understanding the Challenges of Output Feedback LQR

The Linear Quadratic Regulator (LQR) is a cornerstone of modern control theory, providing a systematic way to design controllers for linear systems. Traditionally, solving the LQR problem requires two significant prerequisites: an accurate mathematical model of the system dynamics (defined by matrices $A$ and $B$) and access to the full state vector $x(t)$ at every moment. In practice, however, these conditions are rarely met. System parameters are often unknown or time-varying, and internal states—such as internal temperatures or specific chemical concentrations—might not be directly measurable. Instead, we typically only have access to the system outputs $y(t)$ and inputs $u(t)$.

To bridge this gap, researchers have turned to Reinforcement Learning (RL) and Adaptive Dynamic Programming (ADP). These methods allow for "model-free" control, where the optimal policy is learned directly from data. For systems where the full state is not measurable, a common strategy is to use a "filtered" version of the input and output signals. By passing the available data through a specific mathematical filter, one can create a high-dimensional vector $z(t)$ that essentially "stands in" for the hidden state $x(t)$.

While effective in theory, this approach encounters a significant numerical hurdle. The vector $z(t)$ is often highly redundant. Because the inputs and outputs are generated by the same underlying system, they are mathematically linked. This research focuses on identifying exactly how much of this data is redundant and how to prune it to make RL algorithms more stable and efficient.

## The Problem of Deterministic Redundancy

In continuous-time systems with $n$ states, $m$ inputs, and $p$ outputs, the standard method for output feedback involves constructing a filtered vector $z(t) \in \mathbb{R}^{n(m+p)}$. This vector is composed of two parts:
- $\zeta_u(t) \in \mathbb{R}^{nm}$: Filtered versions of the control inputs.
- $\zeta_y(t) \in \mathbb{R}^{np}$: Filtered versions of the measured outputs.

The primary assumption in earlier literature was that this $n(m+p)$-dimensional vector was necessary to fully capture the dynamics of the $n$-dimensional state $x(t)$. However, this research demonstrates that for any Multi-Input Multi-Output (MIMO) system, there are deterministic linear dependencies within $z(t)$. Specifically, the "intrinsic dimension" of the information needed is actually $n(m+1)$.

When $p > 1$ (meaning there are multiple sensors/outputs), the ambient dimension $n(m+p)$ is strictly greater than the intrinsic dimension $n(m+1)$. This discrepancy leads to $n(p-1)$ redundant directions in the data. In the context of RL, this redundancy causes the "Bellman regression" equations—the mathematical tools used to update the control policy—to become rank-deficient. A rank-deficient matrix cannot be uniquely inverted, leading to numerical instability, failure to converge, or highly sensitive solutions that break down with even tiny amounts of noise.

## Characterizing the Intrinsic Dimension

The core theoretical contribution of this work is the precise characterization of these redundancies for both SIMO and MIMO systems. The authors move the analysis into the Laplace domain (using transfer functions) to determine the number of linearly independent polynomial components.

### Single-Input Multi-Output (SIMO) Systems
For a system with a single input ($m=1$) and multiple outputs, the research proves that the intrinsic dimension is always $2n$. This means that regardless of how many sensors $p$ are added to the system, only $2n$ components of the filtered signals are linearly independent. The remaining $n(p-1)$ signals can be written as linear combinations of the others.

### Multi-Input Multi-Output (MIMO) Systems
The analysis becomes more complex for general MIMO systems. The authors prove that the intrinsic dimension is $n(m+1)$. The logic is split into two subspaces:
1.  **Input Subspace:** The $nm$ components derived from the inputs $u(t)$ are shown to be linearly independent, contributing $nm$ to the dimension.
2.  **Output Contribution:** Despite having $np$ components in the filtered output vector $\zeta_y(t)$, the "new" information they provide—once the input information is accounted for—is only $n$-dimensional.

Summing these gives the total intrinsic dimension of $nm + n = n(m+1)$. This result is significant because it provides a definitive lower bound on the number of parameters needed for model-free output feedback LQR.

## Data-Driven Vector Reduction

Once the intrinsic dimension $r = n(m+1)$ is established, the next challenge is to identify which specific components of the high-dimensional $z(t)$ should be kept. The authors propose a purely data-driven approach using QR decomposition with column pivoting.

The process works as follows:
1.  **Data Collection:** Collect a large batch of filtered input-output data $z(t)$ over a time interval while the system is being "excited" by an exploration signal (like a sum of sine waves).
2.  **Matrix Formation:** Arrange this data into a large matrix $Z \in \mathbb{R}^{N \times n(m+p)}$.
3.  **QR Decomposition:** Perform the decomposition $ZP = QR$. The column pivoting matrix $P$ automatically reorders the columns of $Z$ from most independent to least independent.
4.  **Selection:** By picking the first $r = n(m+1)$ columns according to the pivot order, the algorithm extracts a reduced vector $z_r(t) \in \mathbb{R}^r$.

This method ensures that the resulting $z_r(t)$ contains the most numerically robust set of signals, effectively bypassing the rank deficiency problem without requiring any prior knowledge of the system matrices $A$ or $B$.

## Improved RL Algorithms: PI and VI

With the reduced vector $z_r(t)$ in hand, the authors reformulate two standard RL algorithms: Policy Iteration (PI) and Value Iteration (VI).

### Reduced Policy Iteration
PI starts with a stabilizing controller and iteratively improves it. In the reduced framework, the "Bellman" equation is solved using $z_r(t)$. Because $z_r(t)$ is non-redundant, the least-squares problem used to find the next policy is well-conditioned and has a unique solution.

### Reduced Value Iteration
VI is more flexible as it does not require an initial stabilizing controller, but it is often more sensitive to numerical issues. By using the reduced vector, the authors can implement a "truncated" VI. This involves solving a regression of the form:
$$z_r(t)^T P_r z_r(t) - z_r(t+dt)^T P_r z_r(t+dt) = \int_{t}^{t+dt} (z_r^T Q_z z_r + u^T R u) d\tau$$
Where $P_r$ is the matrix representing the "value" of being in a certain state. The reduction in the number of parameters in $P_r$ significantly speeds up the computation and prevents the algorithm from diverging due to the high condition numbers typical of the full-dimensional approach.

## Empirical Validation: Jet Transport Aircraft

The researchers tested their approach on a model of a jet transport aircraft, a classic MIMO benchmark. For this system, the state dimension $n=4$, with $m=2$ inputs and $p=2$ outputs.
- **Ambient Dimension:** $n(m+p) = 4(2+2) = 16$.
- **Intrinsic Dimension:** $n(m+1) = 4(2+1) = 12$.

The experiments highlighted a dramatic difference between the standard "full" approach and the new "reduced" approach.

### Numerical Conditioning
When using the full 16-dimensional vector, the regression matrix had a condition number of approximately $3.6 \times 10^{17}$. In numerical computing, a condition number this high means the matrix is effectively singular; any attempt to solve an equation with it will result in "garbage" due to rounding errors. By reducing the vector to the 12 independent components, the condition number dropped to $2.4 \times 10^4$—a massive improvement of thirteen orders of magnitude.

### Convergence Behavior
The impact on the learning process was stark. As shown in {fig:failure-of-the-full-formulation-in-value-iteration}, the standard Value Iteration algorithm failed to converge, with its error oscillating wildly and requiring constant resets.

## Conclusion and Significance

This research addresses a fundamental "hidden" problem in data-driven control. While the use of filtered input-output signals has been known to work in principle for unmeasured states, the deterministic redundancies inherent in these signals often make algorithms fail in practice.

By mathematically proving that the intrinsic dimension of a MIMO system's filtered signal space is $n(m+1)$, the authors provide a clear target for data reduction. Their QR-based method for selecting independent components allows these benefits to be realized in a purely model-free way. The result is a more robust, computationally efficient, and numerically stable framework for designing optimal controllers using only the data that is actually available in real-world engineering systems.
