## The Challenge of Safety Under Partial Observability

Ensuring the safety of autonomous systems, such as robotic manipulators, self-driving vehicles, or delivery drones, is a primary concern in control engineering. Standard safety frameworks often rely on the assumption that the system state—its exact position, velocity, and orientation—is perfectly known at every moment. In practice, however, systems operate under partial observability. Control decisions are made using estimates derived from noisy sensors like cameras, LiDAR, or GPS. This discrepancy between the true state $x(s) \in \mathbb{R}^n$ and the estimated state $\hat{x}(s) \in \mathbb{R}^n$ introduces an estimation error $\epsilon(s) = x(s) - \hat{x}(s)$ that can lead to safety violations if not properly accounted for.

Current methods for safety-critical control generally fall into two categories: Hamilton–Jacobi (HJ) reachability and Control Barrier Functions (CBFs). HJ reachability provides global safety certificates by solving a partial differential equation (PDE) to find a value function that identifies all states from which a system can be kept safe. While theoretically rigorous, it is computationally expensive for high-dimensional systems. CBFs, conversely, provide a computationally efficient way to filter control inputs in real-time by enforcing a derivative condition that keeps the system within a safe set. However, both frameworks typically assume full state observability.

This paper introduces the Partially Observable Control Barrier–Value Function (PO-CBVF). This framework extends Control Barrier–Value Functions (CBVFs)—which already combine the global guarantees of HJ reachability with the online efficiency of CBFs—to handle systems with partial observability. The key contribution is a method to rigorously bound the estimation error using conformal prediction and incorporate these bounds into the safety certification process, providing a high-probability guarantee that the true state of the system remains safe.

## Quantifying Uncertainty via Conformal Prediction

To ensure safety under uncertainty, one must first quantify how large the estimation error $\epsilon(s)$ might be. Traditional robust control often assumes a worst-case error bound based on a simplified model of sensor noise. However, modeling the complex interactions between a nonlinear system, its environment, and a sophisticated state estimator (like a Kalman filter or a neural network observer) is difficult.

The authors address this by employing Conformal Prediction (CP), a statistical framework that provides finite-sample, distribution-free coverage guarantees. Instead of relying on an analytical model of the error, CP uses historical data to calibrate an error bound. In the context of this paper, the calibration process involves:

1.  **Data Collection**: Running $M$ offline calibration rollouts where both the true state and the estimated state are recorded.
2.  **Score Computation**: For each rollout $j$, a score $S^{(j)}$ is calculated as the maximum magnitude of the estimation error encountered during that trajectory:
    $$S^{(j)} = \max_{k \in \{0, \dots, N\}} \|\epsilon^{(j)}_k\|$$
3.  **Quantile Calculation**: Given a user-defined risk level $\alpha$ (e.g., $\alpha = 0.05$ for a 95% confidence level), the scores are sorted to find a quantile $q_\alpha$:
    $$q_\alpha = \text{Quantile}(\{S^{(j)}\}_{j=1}^M, 1-\alpha) \approx S^{(\lceil (M+1)(1-alpha) \rceil)}$$

This quantile $q_\alpha$ provides a statistical guarantee: for a new online trajectory, the probability that the estimation error at all sampling times remains within the bound $q_\alpha$ is at least $1 - \alpha$. This approach is particularly powerful because it makes very few assumptions about the underlying noise distribution or the specific estimator used.

## Bridging Discrete Observations and Continuous Motion

A significant challenge in safety-critical control is that sensors provide measurements at discrete time intervals, while the system moves continuously. Even if the estimation error is bounded at the sampling times by $q_\alpha$, the error could potentially grow between those samples.

To bridge this gap, the paper utilizes Grönwall’s inequality. By assuming a Lipschitz-like bound on the rate of change of the error, denoted as $\|\dot{\epsilon}(s)\| \leq L_\epsilon \|\epsilon(s)\| + \bar{w}$, the researchers derive a continuous-time error radius $r_{ct, \alpha}(s; t_k)$. This radius expands the discrete bound $q_\alpha$ as time progresses from the last measurement at $t_k$:

$$r_{ct, \alpha}(s; t_k) = q_\alpha e^{L_\epsilon (s-t_k)} + \frac{\bar{w}}{L_\epsilon} (e^{L_\epsilon (s-t_k)} - 1)$$

This formula ensures that the error bound is valid at every instant, not just at the moments the sensor captures data. This continuous-time bound is essential for formal safety verification, as safety violations often occur in the "inter-sample" periods.

## Tightening the Safety Margin

Once the estimation error is bounded, the next step is to adjust the definition of "safe" to account for the uncertainty. If the original safe set is defined by $\mathcal{L} = \{x : l(x) \geq 0\}$, where $l(x)$ is a function representing the distance to an obstacle, then the system is safe if the true state $x$ is in $\mathcal{L}$.

Since the controller only knows the estimate $\hat{x}$, it must use a more conservative version of the safety function. The authors define a tightened safety margin $\ell_\alpha(\hat{x}, s; t_k)$ in the estimator space. This function represents the worst-case (minimum) safety value among all possible true states $x$ that are consistent with the current estimate $\hat{x}$ and the error bound $r_{ct, \alpha}$:

$$\ell_\alpha(\hat{x}, s; t_k) = \min_{x: \|x-\hat{x}\| \leq r_{ct, \alpha}(s; t_k)} l(x)$$

Effectively, this process "inflates" the obstacles in the environment. If the true state could be anywhere within a radius $r_{ct, \alpha}$ of the estimate, the estimate itself must stay at least that far away from the physical obstacles to guarantee the true state is safe.

## The Partially Observable Control Barrier–Value Function

The core of the methodology is the definition and computation of the PO-CBVF, $B_{\gamma, \alpha}(\hat{x}, t)$. This function represents the maximum possible "safety value" the system can maintain over a finite time horizon, given the dynamics of the estimator and the potential disturbances. It is defined as:

$$B_{\gamma, \alpha}(\hat{x}, t) = \sup_{u(\cdot)} \inf_{\hat{d}(\cdot)} \min_{s \in [t, 0]} \left( e^{\gamma(s-t)} \ell_\alpha(\hat{x}(s), s) \right)$$

In this formulation, $u$ is the control input and $\hat{d}$ represents the lumped disturbances and uncertainties affecting the estimator. The parameter $\gamma$ controls the "exponential decay" behavior characteristic of barrier functions. A value of $B_{\gamma, \alpha}(\hat{x}, t) \geq 0$ implies that there exists a control strategy that keeps the system safe for the remaining time.

The authors prove that this value function can be found by solving a Hamilton-Jacobi-Isaacs (HJI) equation in the estimator space:

$$\frac{\partial B}{\partial t} + \min \{0, H(\hat{x}, \nabla_{\hat{x}} B, t) - \gamma B\} = 0$$

with the terminal condition $B_{\gamma, \alpha}(\hat{x}, 0) = \ell_\alpha(\hat{x}, 0)$. The Hamiltonian $H$ is defined as:

$$H(\hat{x}, p, t) = \max_{u \in U} \min_{\hat{d} \in \hat{D}(t)} p \cdot \hat{f}(\hat{x}, u, \hat{d})$$

The most significant theoretical result of the paper is the high-probability safety guarantee. It states that if the system is controlled such that the barrier condition of the PO-CBVF is satisfied, then the true state $x(s)$ will remain in the safe set $\mathcal{L}$ with a probability of at least $1 - \alpha$:

$$\mathbb{P}(x(s) \in \mathcal{L}, \forall s \in [t, 0]) \geq 1 - \alpha$$

## Online Implementation via Quadratic Programming

While solving the HJI equation is computationally intensive and is done offline, the resulting PO-CBVF can be used for very fast online control. This is achieved through a safety filter implemented as a Quadratic Program (QP).

The safety filter takes a "nominal" control input $u_{nom}$ (which might be designed for performance, like reaching a goal) and modifies it as little as possible to ensure safety. For a system where the estimator dynamics are affine in the control $u$, the QP is formulated as:

$$\min_u \|u - u_{nom}\|^2$$
$$\text{s.t. } \nabla_{\hat{x}} B_{\gamma, \alpha} \cdot \hat{f}(\hat{x}, u, \hat{d}) \geq \gamma B_{\gamma, \alpha} - \frac{\partial B_{\gamma, \alpha}}{\partial t} \quad \forall \hat{d} \in \hat{D}(t)$$

This optimization problem is solved at each control cycle. If the nominal control is already safe, the QP returns $u_{nom}$ unchanged. If the nominal control would lead to a safety violation, the QP finds the closest safe control input. Because QPs can be solved extremely quickly, this approach allows for real-time safety enforcement even on hardware with limited computational power.

## Experimental Verification and Significance

The researchers demonstrated their framework on a planar double integrator system tasked with avoiding obstacles while relying on noisy position measurements. By calibrating the error bound with 500 offline rollouts and choosing $\alpha = 0.05$, they computed a PO-CBVF that accounted for both measurement noise and the lag in the state estimator.

The results showed that the system successfully navigated around obstacles. Crucially, even when the estimated state $\hat{x}$ passed close to an obstacle, the "inflated" safety margin ensured the true state $x$ remained at a safe distance. In their tests, the empirical safety rate actually exceeded the $95\%$ requirement, suggesting that the Grönwall-based propagation adds a layer of healthy conservatism.

This work marks an advancement in robust control by providing a principled way to use data-driven error bounds within a formal safety framework. By moving beyond the assumption of full state observability, the PO-CBVF framework makes high-level safety guarantees more applicable to the messy reality of physical sensors and state estimators.
