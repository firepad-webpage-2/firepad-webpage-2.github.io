## Introduction to mmWave Massive MIMO and Hybrid Beamforming

Millimeter-wave (mmWave) massive Multiple-Input Multiple-Output (MIMO) is a cornerstone technology for modern high-speed wireless networks. By operating at high frequency bands with large available bandwidths and employing arrays with a high number of antennas, these systems can provide the massive data rates required for 5G and 6G applications. However, the physical implementation of these systems faces a significant challenge: hardware cost and power consumption. In a fully digital beamforming system, every single antenna requires its own Radio Frequency (RF) chain, including expensive components like power amplifiers and digital-to-analog converters. For a system with hundreds of antennas, this is practically unfeasible.

To solve this, researchers use "hybrid beamforming." This architecture uses a much smaller number of RF chains than antennas. It splits the beamforming process into two parts: a high-dimensional analog part, which uses inexpensive phase shifters, and a low-dimensional digital part. While this makes the hardware practical, it complicates the task of "channel estimation"—knowing exactly how the signal is distorted as it travels from the transmitter to the receiver. Because the number of RF chains is limited, the receiver only sees a "compressed" version of the signal, making it difficult to reconstruct the full channel state information (CSI) required for precise beamforming.

![system-model](https://paper-assets.alphaxiv.org/figures-normalized/figures/2608.14182v1/img-0.jpeg)
*{fig:system-model}: The architecture of a multi-user hybrid mmWave massive MIMO system, illustrating the interplay between base station precoding, the wireless channel, and user-side combining.*

In a typical setup, a Base Station (BS) with $N_{BS}$ antennas and $N_{RF}$ RF chains serves $K$ users, where each User Equipment (UE) has $N_{UE}$ antennas and $N_{UERF}$ RF chains. The goal is to estimate the channel matrix $H_k$, which characterizes the link between the BS and the $k$-th user. This estimation must be accurate for both the downlink (DL) and the uplink (UL), known as dual-side channel estimation.

## The Challenge of Distributed Data and Privacy

Modern channel estimation often relies on deep learning to "clean up" the noisy, compressed observations received through the hybrid hardware. Traditionally, this requires a central server to collect raw data from all users to train a global neural network. However, this "centralized" approach has two major flaws. First, moving large amounts of raw radio data from many users to a base station consumes massive amounts of bandwidth. Second, raw channel data can reveal sensitive information about a user's location or environment, raising significant privacy concerns.

Federated Learning (FL) offers a solution by allowing users to keep their data local. Instead of sharing raw data, users train a local model and only send the model’s "weights" (parameters) to a central server. The server aggregates these weights and sends an updated global model back to the users. While this protects privacy and avoids raw data transfer, the model parameters themselves must be sent back and forth over many rounds. In wireless systems, the uplink—where users send data to the base station—is often a bottleneck. Every single parameter in the model adds to this communication burden.

This paper identifies a critical gap in current research: most communication-efficient FL methods focus on the *process* of sending updates (like using quantization or sending updates less often). This work instead focuses on the *design* of the estimator itself. It asks: how can we build a neural network that achieves high accuracy with a very small number of parameters? By optimizing the internal "parameter budget" of the estimator, we can significantly reduce the total communication cost over the entire training process.

## Constructing Unified Dual-Side Observations

A key contribution of this work is the creation of a unified way to represent both downlink and uplink signals so they can be processed by the same neural network architecture. In hybrid systems, the observations are naturally compressed.

For the downlink, the system uses standard codebooks to project the received signal. A noisy, structured observation $R_k$ is constructed by projecting the received pilot signals back into the spatial domain using conjugate beamforming bases. This results in a matrix $R_k \in \mathbb{C}^{N_{UE} \times N_{BS}}$ that serves as a coarse, noisy estimate of the true downlink channel $H_k^H$.

For the uplink, the process is slightly different. The users transmit orthogonal pilot signals, and the base station uses a series of $D$ analog combiners. By applying pilot correlation and spatial back-projection, the system generates a structured observation $G_k \in \mathbb{C}^{N_{BS} \times N_{UE}}$. This matrix $G_k$ is a noisy approximation of the uplink channel $H_k$.

By stacking the real and imaginary parts of these matrices, the researchers create a unified input tensor $X_k$. This allows the same "Budget-Aware Recalibrated Refinement Network" (BARRNet) to be used for both UL and DL estimation tasks across the federated network.

## BARRNet: Architecture for Communication Efficiency

The proposed BARRNet is designed to be highly efficient. Instead of simply building a deep, "heavy" network with many layers, the authors utilize a "budget-aware" design. The network is split into three main components: a compact encoder, a channel-wise recalibration module, and a residual refinement head.

![barrnet-architecture](https://paper-assets.alphaxiv.org/figures-normalized/figures/2608.14182v1/img-1.jpeg)
*{fig:barrnet-architecture}: The BARRNet architecture, featuring the compact encoder $E_\phi$, the channel-wise recalibration module $G_\psi$, and the residual refinement head $D_\omega$.*

1.  **Compact Encoder ($E_\phi$):** This module takes the noisy input $X_k$ and extracts initial features $F = E_\phi(X)$. It uses a small number of convolutional layers to keep the parameter count low.
2.  **Channel-wise Recalibration ($G_\psi$):** This is the core "intelligent" part of the model. It uses a squeeze-and-excitation mechanism. It "squeezes" the features into a global descriptor $s$, then uses a tiny bottleneck network to produce weights $g$ for each feature channel. Finally, it "recalibrates" the features by multiplying them by these weights: $F' = g \odot F$. This allows the network to focus on the most important features without needing the massive number of parameters required by a deeper backbone.
3.  **Residual Refinement Head ($D_\omega$):** This part predicts the structured disturbance or noise $\hat{N}$ present in the observation.

The final estimate is produced by subtracting the scaled noise from the original observation:
$$\hat{H} = X - \beta \hat{N}$$
where $\beta$ is a learnable scaling factor. The total set of parameters that need to be synchronized in the federated process is $\eta = \{\phi, \psi, \omega, \beta\}$.

## Federated Learning and the Parameter Budget

The paper uses the standard Federated Averaging (FedAvg) algorithm. In each round $t$, a subset of clients $S_t$ downloads the global model, trains it on their local data to minimize a loss function $L_k(\eta)$, and then uploads the updated parameters.

The local loss function for each client is the mean squared error between the clean channel $Y_k^{(i)}$ and the estimate $f_\eta(X_k^{(i)})$:
$$L_k(\eta) = \frac{1}{N_k} \sum_{i=1}^{N_k} \|Y_k^{(i)} - f_\eta(X_k^{(i)})\|_F^2$$

The total communication cost per round depends directly on the number of parameters $P_{model}$ and the bitwidth of the transmission (e.g., 32-bit floats):
$$B_{round}(t) = |S_t| P_{model} (b_{DL} + b_{UL})$$

The goal of this research is to minimize the estimation error while staying under a total communication budget $B_{max}$ over $T$ rounds:
$$\sum_{t=1}^T B_{round}(t) \leq B_{max}$$

By making the model BARRNet compact and efficient through smart parameter allocation, the researchers reduce $P_{model}$ while maintaining high accuracy, effectively "spending" the communication budget more wisely.

## Performance and Communication Trade-offs

The researchers conducted extensive simulations to compare BARRNet against several baselines, including classical linear methods (LMMSE) and other deep learning models like DnCNN.

![nmse-vs-communication](https://paper-assets.alphaxiv.org/figures-normalized/figures/2608.14182v1/img-3.jpeg)
*{fig:nmse-vs-communication}: Normalized Mean Squared Error (NMSE) as a function of the cumulative communication cost in Gbits. BARRNet achieves lower error for the same communication expenditure compared to other models.*

A critical finding was the comparison between BARRNet and a "Backbone-only" version of the same network (where the recalibration module was removed). BARRNet only adds about 2.7% more parameters than the Backbone-only model. However, to reach a target accuracy (NMSE of -13 dB), BARRNet required only $1.93 \text{ Gbits}$ of total communication, while the Backbone-only model required $2.72 \text{ Gbits}$. This represents a **28.9% reduction in communication cost**. This proves that intelligently allocating a small number of parameters to recalibrate features is much more efficient than simply making the main network larger.

![target-nmse-cost](https://paper-assets.alphaxiv.org/figures-normalized/figures/2608.14182v1/img-4.jpeg)
*{fig:target-nmse-cost}: A comparison of the cumulative communication required to reach specific NMSE targets. BARRNet consistently requires the least amount of data transfer.*

The study also showed that BARRNet is compatible with other compression techniques. For example, when combined with 8-bit quantization for the uplink (instead of the standard 32-bit), the communication cost dropped even further while maintaining similar accuracy. This demonstrates that budget-aware estimator design and traditional communication compression are complementary strategies.

## Scalability and Dual-Side Results

The paper also validated that BARRNet works well for both the base station side (uplink) and the user side (downlink). While there is a slight performance difference due to the different noise levels and hardware processing (an offset of $\Delta_{SNR} = 1.53 \text{ dB}$ was used for calibration), both estimation tasks showed strong convergence and accuracy.

Furthermore, the system proved robust to changes in the network environment. Whether there were 4 users or 8, and even if only 50% of the users participated in each federated round, BARRNet maintained its performance edge. This scalability is vital for real-world deployments where user participation and network size are constantly changing.

## Conclusion

This work provides a new perspective on communication-efficient federated learning for wireless systems. Instead of only looking at how to compress model updates, it demonstrates that the internal architectural design of the channel estimator is equally important. By using a "budget-aware" approach—specifically through lightweight channel-wise recalibration—BARRNet achieves high-fidelity dual-side channel estimation with a significantly lower communication footprint. This approach addresses the twin challenges of privacy and overhead, paving the way for more efficient and practical machine learning in future mmWave massive MIMO networks.
