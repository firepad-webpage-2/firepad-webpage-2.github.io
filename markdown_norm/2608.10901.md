## Integrating Reconfigurable Intelligent Surfaces into Next-Generation Networks

The evolution toward 6G and next-generation (NextG) wireless networks is defined by the need for unprecedented data rates, hyper-reliability, and ubiquitous connectivity. To meet these demands, researchers are exploring technologies that can go beyond traditional signal processing at the transmitter and receiver. One such technology is the Reconfigurable Intelligent Surface (RIS). An RIS consists of an array of passive reflecting elements that can be electronically controlled to shift the phase and amplitude of incident electromagnetic waves. By doing so, an RIS can effectively "program" the wireless environment, creating favorable propagation paths where none existed or suppressing destructive interference.

In a multi-user multiple-input single-output (MU-MISO) system, the performance depends heavily on the coordination between the active precoding at the Base Station (BS) and the passive reflection at the RIS. The BS must steer its beams toward specific users while the RIS simultaneously adjusts its surface to enhance those beams and mitigate interference between users. This joint optimization, however, introduces a significant challenge: signaling overhead. For the BS to calculate the optimal settings, it requires precise information about the channels between the BS and the RIS, and between the RIS and the users. Reporting this information back to the BS can consume a large portion of the available uplink bandwidth, potentially negating the spectral efficiency gains offered by the RIS.

This research addresses this bottleneck by proposing a novel, standard-compatible feedback metric called the Channel Information Indicator (CII). By integrating BS precoding and RIS configuration into a single feedback report, the CII framework aims to provide the benefits of joint optimization with a minimal signaling footprint.

## The MU-MISO System Model and the Optimization Problem

The study focuses on a downlink scenario where a BS equipped with $N_{TA}$ transmit antennas serves $N_{UE}$ single-antenna users. The communication is assisted by an RIS with $N_{RIS}$ reflecting elements. The system utilizes Orthogonal Frequency-Division Multiplexing (OFDM) across $N_{SC}$ subcarriers to manage frequency-selective fading.

The end-to-end channel for any given user is a combination of two main paths: the direct path from the BS to the user and the reflected path through the RIS. Mathematically, the effective channel for user $u$ at subcarrier $k$, denoted as $\mathbf{h}_{u,k}^H$, is represented as:

$$
\mathbf{h}_{u,k}^H = \mathbf{d}_{u,k}^H + \mathbf{g}_{u,k}^H \Phi_k \mathbf{G}_k
$$

In this expression, $\mathbf{d}_{u,k}$ represents the direct link, $\mathbf{G}_k$ is the channel from the BS to the RIS, and $\mathbf{g}_{u,k}$ is the channel from the RIS to the user. The matrix $\Phi_k$ is the RIS configuration matrix, which is a diagonal matrix containing the phase shifts and amplitude responses of the $N_{RIS}$ elements.

The received signal at the user is not just the intended message but also includes interference from signals meant for other users and additive noise. The received signal $y_{u,k}$ is expressed as:

$$
y_{u,k} = \mathbf{h}_{u,k}^H \mathbf{w}_{u,k} x_{u,k} + \sum_{i \neq u} \mathbf{h}_{u,k}^H \mathbf{w}_{i,k} x_{i,k} + n_{u,k}
$$

Here, $\mathbf{w}_{u,k}$ is the precoding vector for user $u$, $x_{u,k}$ is the transmitted data symbol, and $n_{u,k}$ is the noise. The system's objective is to maximize the average sum spectral efficiency $R$, defined as:

$$
R = \frac{1}{K} \sum_{k=1}^K \sum_{u=1}^{N_{UE}} \log_2(1 + \text{SINR}_{u,k})
$$

where the Signal-to-Interference-plus-Noise Ratio (SINR) is:

$$
\text{SINR}_{u,k} = \frac{|\mathbf{h}_{u,k}^H \mathbf{w}_{u,k}|^2}{\sum_{i \neq u} |\mathbf{h}_{u,k}^H \mathbf{w}_{i,k}|^2 + \sigma^2
$$

Maximizing this value requires a joint search for the best BS precoding matrix and the best RIS configuration. Because these variables are coupled and the RIS elements often have discrete, constrained phase shifts, this optimization problem is non-convex and computationally prohibitive for real-time operation in dynamic environments.

## The CII Reporting Framework

To make joint optimization practical, the researchers propose moving away from real-time continuous optimization toward a codebook-based approach. In this setup, both the BS and the users possess a predefined "menu" of possible configurations. Instead of the user sending back raw channel data, it simply points to the best configuration in the menu.

Current standards like 5G NR use the Precoding Matrix Indicator (PMI) to select the BS precoder. However, PMI does not account for the RIS. The proposed Channel Information Indicator (CII) extends the existing Channel State Information Reference Signal (CSI-RS) framework to include the RIS. The core innovation of the CII is that it indexes a pair of configurations: one for the BS precoder and one for the RIS reflection.

![current-and-proposed-csi-rs-reporting-formats](https://paper-assets.alphaxiv.org/figures-normalized/figures/2608.10901v1/Figures/CII_Case.jpg)
*{fig:current-and-proposed-csi-rs-reporting-formats}: Comparison of standard CSI-RS report formats with the proposed CII-based framework, which consolidates BS and RIS selection into a single metric.*

The framework compares several reporting strategies:
1.  **PMI-Based Feedback:** The RIS remains in a fixed, default state, and the user selects the best BS precoder.
2.  **RCI-Based Feedback:** The BS uses a default precoder, and the user selects the best RIS configuration (RIS Configuration Indicator).
3.  **CII-Based Feedback:** The user selects a single index $q^{\star}_{CII}$ from a combined codebook $\mathcal{C}$ that contains optimized pairs of BS precoders and RIS configurations $(W^{(q)}, \Phi^{(q)})$.
4.  **Separate PMI and RCI Feedback:** The user independently selects the best BS precoder and the best RIS configuration from their respective full codebooks. While this offers the most flexibility, it requires twice the feedback bits and a significantly larger search effort.

By using the CII, the system maintains a feedback budget $B_{CII}$ similar to conventional systems (e.g., 12 bits) while achieving the benefits of coordinated beamforming.

## Offline Codebook Design

The effectiveness of a codebook-based approach depends entirely on how well the codebooks represent the possible channel states. The paper details a deterministic offline procedure for generating these codebooks.

### Precoding Matrix (PM) Codebook
The PM codebook $\mathcal{W}$ is generated using a Type-II-inspired procedure. It utilizes an oversampled Discrete Fourier Transform (DFT) dictionary to cover the angular space. For each index, a local beam subset is formed by selecting adjacent steering vectors. These are then combined using phase-only coefficients to create a normalized precoding vector for each user. This ensures that the BS can form narrow, high-gain beams toward the UEs.

### RIS Configuration (RC) Codebook
The RC codebook $\mathcal{P}$ is generated in two stages. First, the far-field angular space of the RIS is divided into regions. Each region corresponds to a specific "look direction" for the RIS. Second, a multi-beam design is implemented using a Majorization-Minimization (MM) algorithm. This algorithm synthesizes a reflection pattern that can serve multiple users simultaneously by minimizing the error between a target multi-beam response and the actual RIS reflection. This stage is crucial because it accounts for the physical limitations of the RIS, such as the fact that changing the phase shift of an element often slightly changes its reflection amplitude.

## Performance Analysis and Results

The researchers evaluated the CII framework through extensive simulations of a 3D deployment. The setup included a BS with 32 antennas and an RIS with 1024 elements serving 4 users at 7.5 GHz.

![sum-rate-performance-comparison](https://paper-assets.alphaxiv.org/figures-normalized/figures/2608.10901v1/x2.png)
*{fig:sum-rate-performance-comparison}: Average sum rate performance as a function of the number of feedback bits $B$, comparing PMI, RCI, CII, and the separate feedback upper bound (UB).*

The results highlighted three key findings:
1.  **Superior Efficiency:** The CII-based scheme consistently outperformed the PMI-only and RCI-only baselines. For instance, with a 12-bit feedback budget, the CII achieved a significantly higher sum rate than either single-aspect optimization.
2.  **Overhead Reduction:** The CII scheme reached a performance level (e.g., 8 bit/s/Hz) using only about 5-6 feedback bits, whereas the standard PMI and RCI schemes required nearly 12 bits to reach a lower converged rate. This suggests that the CII is much more efficient at using the available feedback resources.
3.  **Search Complexity:** While the separate feedback (Upper Bound) achieved the highest rates, it did so at the cost of exponential complexity. As shown in the researchers' analysis, the number of online evaluations for separate feedback grows as $O(2^{2B})$, while for CII, it remains at $O(2^B)$. For a 12-bit system, this is the difference between 4,096 evaluations and over 16 million evaluations at the UE.

## Conclusion and Significance

This work presents a practical path forward for the deployment of RIS in multi-user NextG networks. By introducing the Channel Information Indicator (CII), the authors have demonstrated that it is possible to achieve the gains of joint BS-RIS optimization without the prohibitive signaling overhead and computational complexity that typically accompany such problems.

The significance of the CII framework lies in its compatibility with the existing CSI-RS structure. Rather than proposing a radical departure from current cellular standards, it offers an evolutionary step that could be integrated into future 6G specifications. By consolidating the feedback for active and passive components into a single index, the CII enables the network to adapt to the wireless environment more effectively, ultimately leading to higher spectral efficiency and more reliable connectivity for end-users. Future developments may further refine these codebooks using machine learning to adapt to specific urban or industrial deployment environments, further enhancing the utility of the CII framework.
