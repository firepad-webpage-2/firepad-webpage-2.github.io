In the study of cooperative game theory, researchers often seek ways to distribute the total profit or cost of a joint enterprise among its participants in a manner that is both stable and fair. Flow games represent a specific class of these games where the "profit" is determined by the maximum flow of a commodity (such as data, electricity, or goods) through a network controlled by several players. While classical models assume players own all parts of the network, modern infrastructure often involves shared or "public" components. This paper investigates "Flow Games with Public Arcs," specifically focusing on how to efficiently compute fair allocations—known as the least core and the nucleolus—when the network includes these shared resources.

## Introduction to Flow Games and Public Arcs

A cooperative flow game is defined on a directed network $G = (V, E)$ with a source $s$ and a sink $t$. In a traditional flow game, each arc in the network is owned by a specific player. The value of a coalition of players is the maximum flow that can be sent from $s$ to $t$ using only the arcs they control. However, real-world systems like the internet or transportation networks often include infrastructure that no single player owns or that is freely available to everyone, such as public highways or shared exchange points.

The paper models this by partitioning the set of arcs $E$ into two sets: private arcs $N$, which represent the set of players (each player $i \in N$ controls one arc), and public arcs $N^0$, which can be used by any coalition of players at no cost. In a "simple" flow game, every arc has a capacity of $c(e) = 1$. For any subset of players $S \subseteq N$, the characteristic function $v(S)$ denotes the maximum flow possible from $s$ to $t$ using the arcs in $S \cup N^0$. The goal is to distribute the total value $v(N)$ (the maximum flow available to the "grand coalition" of all players) as an allocation $x = (x_i)_{i \in N}$, where $x_i$ is the share given to player $i$.

## Fairness and Stability: The Core and the Nucleolus

To determine a "fair" allocation, game theorists use several solution concepts. The most fundamental is the **core**. An allocation $x$ is in the core if it is efficient (the total value is distributed: $x(N) = v(N)$) and stable (no group $S$ can get more by acting alone: $x(S) \geq v(S)$). 

However, in many flow games, the core is empty—meaning no matter how you divide the profit, some group will always have an incentive to break away. To handle this, the **least core** provides a relaxation. It identifies allocations that minimize the "dissatisfaction" of any coalition. This dissatisfaction is measured by the excess, $e(S, x) = x(S) - v(S)$. The least core seeks to maximize the minimum excess across all possible coalitions:

$$
\begin{aligned}
\text{maximize} \quad & \epsilon \\
\text{subject to} \quad & x(S) \geq v(S) + \epsilon, \quad \forall \emptyset \neq S \subsetneq N \\
& x(N) = v(N) \\
& x_i \geq 0, \quad \forall i \in N
\end{aligned}
$$

While the least core is a set of allocations, the **nucleolus** is a unique allocation within the least core. It is the distribution that lexicographically maximizes the vector of sorted excesses, making it arguably the most "fair" single point in the game.

## Overcoming Exponential Complexity

The primary difficulty in computing the least core or the nucleolus lies in the number of constraints. Since there are $n$ players, there are $2^n$ possible coalitions $S$. Checking every single coalition to ensure $x(S) \geq v(S) + \epsilon$ is computationally impossible for even moderately sized networks.

The researchers overcome this by transforming the coalition-based constraints into flow-based constraints. They prove that for simple flow games with public arcs, the least core can be defined using integer flows rather than subsets of players. Specifically, the condition $x(S) \geq v(S) + \epsilon$ for all $S$ is equivalent to ensuring that for every possible unit flow $f$ from $s$ to $t$, the total allocation along the private arcs of that flow is at least $1 + \epsilon$. This transformation reduces the problem to one that can be solved using minimum cost flow techniques, which are efficient and run in polynomial time.

## Characterizing the Least Core via Potential Functions

A major contribution of this work is the characterization of the least core using "potential functions." This approach maps the game-theoretic problem onto a physical-like model of the network.

The authors introduce the concept of **universal flows**—flows that are "tight" (meaning the allocation exactly equals the value plus the minimum excess) for every allocation in the least core. By analyzing these flows, they partition the network arcs into three categories:
1.  **Set M**: Arcs that are always used by every universal flow.
2.  **Set A**: Arcs that are used by some, but not all, universal flows.
3.  **Set R**: Arcs that are never used by any universal flow.

They prove a surprising structural result: all private arcs in set $R$ must receive an allocation of zero in the least core. Furthermore, any allocation $x$ in the least core can be represented by a potential function $\pi$ assigned to the nodes of the network. For any private arc $e = (u, v)$ in set $A$, the allocation is simply the difference in potential between its endpoints: $x(e) = \pi(u) - \pi(v)$.

![arc-partitioning-and-potentials](https://paper-assets.alphaxiv.org/figures-normalized/figures/2606.23288v1/ex2.png)
*{fig:arc-partitioning-and-potentials}: An illustration of how potential values assigned to nodes determine the fair allocation $x(e)$ for arcs in the network.*

This characterization allows the entire least core to be described by a small number of linear constraints on these node potentials, making it much easier to analyze the set of all stable allocations.

## Computing the Nucleolus in Balanced Games

While the least core provides a set of candidates for fair distribution, the nucleolus identifies the best one. The paper provides a polynomial-time algorithm to compute the nucleolus for "balanced" games (games where the core is not empty).

The algorithm relies on the **Picard-Queyranne (P-Q) decomposition**. This method decomposes the residual network of a maximum flow into strongly connected components (SCCs). These components help identify "veto players"—arcs that are absolutely essential for maintaining the maximum flow and thus must receive some share of the value.

![network-decomposition-for-nucleolus-calculation](https://paper-assets.alphaxiv.org/figures-normalized/figures/2606.23288v1/ex3.png)
*{fig:network-decomposition-for-nucleolus-calculation}: The P-Q decomposition of a network into strongly connected components. The red and green arcs represent "jumps" between components that are critical for determining the unique nucleolus allocation.*

The computation proceeds through a series of recursive steps:
1.  **Identify Jumps**: The algorithm identifies "jumps," which are paths or arcs that connect different components in the decomposition.
2.  **Solve Recursive LPs**: Instead of looking at all $2^n$ coalitions, the algorithm solves a sequence of much smaller linear programs. Each program focuses on the potential differences across these jumps and the allocations of veto players.
3.  **Refinement**: Each step of the recursion fixes the values of more variables until a unique allocation—the nucleolus—is reached.

By leveraging the potential function characterization and the P-Q decomposition, the authors show that each of these steps can be completed in polynomial time. This ensures that even for large networks, the unique fair allocation can be found efficiently.

## Practical Significance and Future Directions

The introduction of public arcs significantly improves the realism of flow games. By accounting for shared infrastructure, this model becomes applicable to modern logistical and digital networks. The shift from exponential coalition constraints to polynomial potential-based constraints is a vital technical advancement that makes these game-theoretic solutions practical for real-world engineering and economic problems.

While the paper provides a complete solution for the nucleolus when the core is non-empty, it also highlights remaining challenges. Specifically, the researchers conjecture that computing the nucleolus when the core is empty (the "unbalanced" case) is significantly harder (NP-hard). Additionally, extending these results to networks with arbitrary arc capacities (general-capacity flow games) remains an open area for exploration. This work serves as a foundation for future research into more complex, multi-capacity shared resource networks.
