## Inference in Scientific Function Spaces

Scientific inquiry frequently involves reconstructing continuous physical fields or unknown functions from sparse, noisy measurements. Whether estimating atmospheric temperature distributions from weather stations, recovering a black hole's image from interferometry data, or identifying the conductivity coefficient of a subsurface rock formation from fluid pressure readings, the underlying problem is one of Bayesian inference. We seek to characterize the posterior distribution of a high-dimensional (often theoretically infinite-dimensional) function given limited observations and a prior understanding of the system's physics or statistics.

Traditionally, Gaussian Processes (GPs) have served as the standard tool for functional regression due to their principled uncertainty quantification and analytical tractability. However, many real-world processes are governed by complex, non-Gaussian statistics—such as the sharp gradients in fluid dynamics or the structured sparsity of astronomical images—that GPs cannot easily capture. Furthermore, scientific "inverse problems" often involve indirect measurements. In these cases, the observations are not of the function itself, but of the output of a forward operator (like a Partial Differential Equation, or PDE) that takes the function as input. 

Recent advancements in generative modeling have introduced "Flow Matching" and "Diffusion" methods to function spaces. While these models learn to generate samples from complex function distributions, they often lack a unified mechanism to perform likelihood-guided inference across both direct regression and indirect inverse problems. Flow Annealing Posterior Sampling (FAPS) addresses this by providing a framework that leverages pretrained function-space flow-matching priors to perform efficient, principled Bayesian sampling.

## Foundations of Operator Flow Matching

FAPS is built upon the framework of Operator Flow Matching (OFM). Unlike standard generative models that operate on fixed-resolution pixel grids, OFM models the probability flow in the space of functions. The goal is to learn a continuous-time transport map that transforms a simple reference measure (typically a Gaussian process) into a complex target data distribution.

In OFM, a neural operator $v_\theta$ is trained to represent a velocity field. This field guides the transformation of samples over a normalized time interval $t \in [0, 1]$. To learn this, the model uses an independent-coupling objective: it draws a sample $u_0$ from the noise distribution and a sample $u_1$ from the target data distribution, then constructs a linear interpolation path:
$$
u_t = t u_1 + (1 - t) u_0 + \sigma_{\min} \xi
$$
where $\xi$ is small Gaussian noise for stability. The neural operator $v_\theta$ is trained to predict the conditional velocity required to reach the target function $u_1$ from the noisy intermediate state $u_t$. Because the model uses operator architectures (like Fourier Neural Operators), it inherits discretization flexibility. This means the prior can be queried at any set of spatial coordinates $X$, and the resulting samples remain consistent regardless of the resolution chosen at test time.

This path induces a "bridge kernel" $q_t(u_t, X | u_1, X) = \mathcal{N}(t u_1, X, s(t)^2 \Sigma_{X,0})$, which describes the distribution of a noisy state at time $t$ given that it will eventually reach the clean state $u_1$ at time $t=1$. This bridge is a core component of the FAPS sampling process.

## The FAPS Algorithm: Anchoring, Correcting, and Re-bridging

FAPS provides a unified approach to two classes of problems using the observation model $y = A(u_1) + \epsilon$, where $y$ is the data, $u_1$ is the unknown function, $A$ is an observation operator, and $\epsilon \sim \mathcal{N}(0, \sigma_y^2 I)$ is measurement noise. 
1.  **Functional Regression:** $A(u_1) = P_\Omega u_1$, where $P_\Omega$ samples the function at specific coordinates $\Omega$.
2.  **PDE Inverse Problems:** $A(u_1) = P_\Omega G_\phi(u_1)$, where $G_\phi$ is a PDE solver mapping an input field to a solution field.

The target is the posterior distribution $\pi_{y,1}(du_1) \propto p(y | u_1) \mu_1(du_1)$. FAPS samples from this distribution by iteratively refining a set of particles through an annealing schedule $0 = t_0 < t_1 < \dots < t_K = 1$. Each iteration consists of three main steps.

### Flow Transport (Endpoint Anchoring)
Starting from a noisy state $u_{t_k}^{(i)}$ at time $t_k$, the algorithm first asks: "Based on the prior alone, what is the most likely clean function this noisy sample will become?" It answers this by integrating the learned flow $v_\theta$ forward to the final time $t=1$. This produces a prior-consistent "anchor" $\hat{u}_k = \Phi_{\theta, t_k \to 1}(u_{t_k})$. This anchor provides a local point of reference for the prior in the high-dimensional function space.

### Likelihood-Guided Langevin Correction
The anchor $\hat{u}_k$ is likely not consistent with the actual observations $y$. FAPS corrects this by performing Langevin dynamics. It treats the anchor as the mean of a local Gaussian approximation of the prior and then "nudges" the sample towards the observations using the gradient of the likelihood.

For direct regression, the likelihood gradient is $\frac{1}{\sigma_y^2} P_\Omega^T (y - P_\Omega u_1)$. For inverse problems, it requires the adjoint of the PDE solver's derivative, $\frac{1}{\sigma_y^2} J_{G_\phi}(u_1)^* P_\Omega^T (y - P_\Omega G_\phi(u_1))$, which propagates the error in the solution back to the input field. The Langevin steps $u_1^{(\ell)}$ allow the sample to find a balance between following the prior (staying near the anchor) and matching the data.

### Re-bridging
Once a corrected clean sample is obtained, it must be moved to the next time step in the annealing schedule. This is done using the bridge kernel $q_{t_{k+1}}(du_{t_{k+1}} | u_{\text{clean},k})$. By adding back a precise amount of noise, the algorithm transitions the sample to a slightly "cleaner" noisy state $u_{t_{k+1}}$, ready for the next iteration. This cycle continues until $t=1$, where the noise vanishes and the particles represent samples from the posterior.

## Geometry and Low-Rank Preconditioning

A major challenge in function-space inference is that observations are often sparse. A gradient update at a single point $\Omega$ might only affect that specific coordinate, leading to "spiky" or incoherent updates that do not look like valid functions from the prior.

FAPS solves this by incorporating the inherent geometry of the function space. It uses a preconditioner $C_X$, which is the empirical covariance of the target distribution. This covariance is calculated offline by generating a large batch of clean samples $\Phi_{\theta, 0 \to 1}(u_0^{(j)})$ where $u_0^{(j)} \sim \gamma_X$ from the prior. Since the full covariance matrix can be massive, FAPS uses a low-rank approximation:
$$
Q_r \Lambda_r Q_r^T + \sigma_{\text{res}}^2 I
$$
By applying this preconditioner to the likelihood gradient, a local measurement update is automatically propagated to other unobserved regions based on how they typically correlate in the data. For example, if the prior knows that fluid velocity at one point is highly correlated with velocity nearby, the preconditioner ensures that updating one point smoothly updates its neighbors, maintaining physical coherence.

## Evaluation and PDE Inverse Problems

The effectiveness of FAPS is demonstrated across a variety of complex tasks. In functional regression, it significantly outperforms Neural Processes, which often struggle with uncertainty calibration and resolution consistency. FAPS maintains high fidelity even when the number of query points increases, as shown in {fig:function-space-regression-performance}.

In the context of PDE inverse problems, FAPS was tested on Darcy flow, the Poisson equation, the Helmholtz equation, and the Navier-Stokes equations. In these tasks, the model must infer an underlying property (like a permeability field) from noisy, sparse measurements of a resultant field (like fluid pressure).

As shown in {fig:pde-inverse-problem-examples}, FAPS recovers posterior samples that capture the dominant structures of the ground truth input fields. The samples are not identical, reflecting the inherent uncertainty of the problem, but they are all physically plausible and consistent with the data. Quantitatively, FAPS achieves reconstruction accuracy comparable to specialized diffusion-based PDE samplers while being significantly faster. For instance, in Poisson inverse problems, FAPS is roughly $1.5\times$ to $2.3\times$ faster than diffusion baselines.

## Practical Significance and Zero-Shot Super-resolution

One of the most powerful features of the FAPS framework is its ability to perform "zero-shot" inference at higher resolutions than those used during training. Because the underlying OFM prior is an operator, it is not tied to a specific grid. 

In experiments with Darcy flow, a prior trained on a standard grid was used to perform inverse inference on a much finer $160 \times 160$ mesh. The algorithm successfully identified the sharp interfaces of the coefficient field using only a tiny fraction of solution measurements. This demonstrates that the prior captures the fundamental "essence" of the function space rather than just memorizing a specific pixel arrangement.

By decoupling prior learning from likelihood-guided inference, FAPS offers a versatile tool for scientific machine learning. A single pretrained prior can be reused for many different tasks—different sensors, different noise levels, or even different physical forward models—without needing to be retrained. This efficiency, combined with robust uncertainty quantification and the ability to exploit the geometric correlations of function spaces, makes FAPS a practical framework for real-world scientific and engineering challenges.
