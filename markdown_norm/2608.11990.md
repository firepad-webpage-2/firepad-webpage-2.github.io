## Generalizing Degree-Constrained Spanning Trees

A spanning tree is a fundamental structure in graph theory, defined as a subgraph that connects all vertices of a parent graph without forming any cycles. Historically, the study of these trees has focused on their existence and enumeration. For instance, Cayley's formula established that for a complete graph $K_n$ (where every vertex is connected to every other vertex), the total number of spanning trees is:

$$\tau(K_n) = n^{n-2}$$

Similarly, for a complete bipartite graph $K_{m,n}$, the number of spanning trees is given by:

$$\tau(K_{m,n}) = m^{n-1} n^{m-1}$$

In recent years, researchers have turned their attention to spanning trees that satisfy specific degree constraints. One notable example is the "odd spanning tree," where every vertex in the tree must have an odd degree. Recent studies have derived existence conditions and exact formulas for counting these trees in complete and bipartite graphs.

The work by Zhidan Yan and Wei Wang extends this specific line of inquiry by introducing a broader concept: the $\ell$-congruent spanning tree. For a positive integer $\ell$, a spanning tree is $\ell$-congruent if the degree of every vertex in the tree is congruent to one modulo $\ell$. This is expressed mathematically as $d_T(v) \equiv 1 \pmod{\ell}$ for every vertex $v$.

This new definition provides a unifying framework. When $\ell=1$, the condition becomes $d_T(v) \equiv 1 \pmod{1}$, which is always true for any degree. Thus, a 1-congruent spanning tree is simply an ordinary spanning tree. When $\ell=2$, the condition is $d_T(v) \equiv 1 \pmod{2}$, meaning every vertex has an odd degree. This encompasses the previously studied odd spanning trees. By exploring values of $\ell \geq 3$, the authors expand the theoretical landscape to a much wider class of constrained structures.

## Existence and the Handshaking Lemma

The first challenge in studying $\ell$-congruent spanning trees is determining whether a graph can support such a structure. The authors establish a necessary condition based on the order $n$ (number of vertices) of the graph. This condition arises from the Handshaking Lemma, a basic graph theory principle stating that the sum of all vertex degrees in a graph is equal to twice the number of edges.

For any spanning tree $T$ with $n$ vertices, the number of edges is exactly $n-1$. Therefore:

$$\sum_{v \in V(T)} d_T(v) = 2(n-1)$$

If we assume the tree is $\ell$-congruent, then each $d_T(v)$ contributes $1 \pmod{\ell}$ to the sum. Summing over all $n$ vertices gives:

$$\sum_{v \in V(T)} d_T(v) \equiv n \pmod{\ell}$$

Combining these two equations leads to the congruence:

$$n \equiv 2(n-1) \pmod{\ell}$$

Simplifying this expression yields $n \equiv 2n - 2 \pmod{\ell}$, which reduces to:

$$n \equiv 2 \pmod{\ell}$$

This result is significant because it dictates the possible sizes of graphs that can contain $\ell$-congruent spanning trees. For $\ell=2$, it implies that $n$ must be even, which aligns with existing requirements for odd spanning trees. For $\ell=3$, the graph must have $2, 5, 8, \dots$ vertices.

## Minimum Degree and the Greedy Algorithm

While $n \equiv 2 \pmod{\ell}$ is a necessary condition, it is not always sufficient. A graph must also be sufficiently "dense"—having enough edges—to accommodate the specific degree requirements. The authors define a sufficient condition based on the minimum degree $\delta(G)$, which is the smallest number of neighbors any vertex has in the graph $G$.

They demonstrate that if $n \equiv 2 \pmod{\ell}$ and the minimum degree satisfies:

$$\delta(G) > \frac{(\ell-1)n}{\ell}$$

then the graph $G$ is guaranteed to contain an $\ell$-congruent spanning tree. The proof of this condition is constructive, meaning it provides a step-by-step algorithm to build the tree. 

### The Construction Algorithm

The algorithm proceeds greedily to build the tree $T$ from an initial edge:

1.  **Initialization:** Select an arbitrary edge in $G$ to form the initial tree $T$. This starting tree has 2 vertices, both with degree 1, which satisfies $1 \equiv 1 \pmod{\ell}$. Note that $2 \equiv 2 \pmod{\ell}$ for the number of vertices.
2.  **Iterative Growth:** Look for a vertex $v$ already in the tree $T$ that has at least $\ell$ neighbors currently outside the tree.
3.  **Expansion:** If such a vertex $v$ and neighbors exist, add $\ell$ edges connecting $v$ to $\ell$ new vertices.
4.  **Property Maintenance:** This step increases the degree of $v$ by $\ell$, so if $v$ previously satisfied $d_T(v) \equiv 1 \pmod{\ell}$, it still does ($1 + \ell \equiv 1 \pmod{\ell}$). The $\ell$ new vertices added are "leaves" with degree 1, so they also satisfy the congruence.
5.  **Termination:** Repeat until no vertex in the current tree has $\ell$ neighbors outside the tree.

By showing that the algorithm only stops when it has covered all $n$ vertices (under the minimum degree condition), the authors prove the existence of the spanning tree. The proof relies on analyzing the "external degree" $\Delta_S(T)$, which is the maximum number of neighbors any vertex in the tree has in the set of vertices not yet in the tree. The authors show that if the algorithm terminated early, the condition $\Delta_S(T) \leq \ell - 1$ would eventually lead to the contradiction:

$$n(\ell-2) < \ell^2 - 2\ell - 2$$

This contradiction proves that the tree must span the entire graph. Interestingly, for the case $\ell=2$, this greedy algorithm offers a more direct and simplified construction method than those found in prior literature on odd spanning trees.

## Analytical Methods for Enumeration

To count the number of $\ell$-congruent spanning trees in highly structured graphs like complete graphs ($K_n$) and complete bipartite graphs ($K_{m,n}$), the research utilizes complex analysis and generating functions. Specifically, they use the "roots-of-unity filter."

The problem starts with a known combinatorial result: the number of spanning trees with a specific degree sequence $d_1, d_2, \dots, d_n$ is $(n-2)! / \prod (d_i - 1)!$. To count only those where $d_i \equiv 1 \pmod{\ell}$, one needs to sum this expression over all sequences where $d_i - 1$ is a multiple of $\ell$. 

The authors define a formal power series $f_{\ell}(x)$ that includes only those terms where the exponent is a multiple of $\ell$:

$$f_{\ell}(x) = \sum_{k=0}^{\infty} \frac{x^{k\ell}}{(k\ell)!}$$

Using properties of the complex roots of unity, they express this function as a sum of exponentials:

$$f_{\ell}(x) = \frac{1}{\ell} \sum_{j=0}^{\ell-1} \exp(\zeta^j x)$$

where $\zeta = \exp(2\pi i / \ell)$ is the primitive $\ell$-th root of unity. This mathematical identity allows the researchers to transform a difficult discrete counting problem into a problem of extracting coefficients from an exponential function, which is much more manageable.

## Counting Trees in Complete Graphs

By applying the roots-of-unity filter to the generating function for spanning trees of $K_n$, the authors derive an exact formula for $\tau_{\ell}(K_n)$:

$$\tau_{\ell}(K_n) = \frac{1}{\ell^n} \sum_{\sum k_j = n, k_j \geq 0} \frac{n!}{k_0! k_1! \cdots k_{\ell-1}!} \left( \sum_{p=0}^{\ell-1} k_p \zeta^p \right)^{n-2}$$

In this formula, the summation is over all ways to partition the $n$ vertices into $\ell$ groups of size $k_0, k_1, \dots, k_{\ell-1}$. The term $\sum k_p \zeta^p$ represents a weighted sum of roots of unity.

### Special Case: Ordinary Spanning Trees ($\ell=1$)
If $\ell=1$, then $\zeta = e^0 = 1$. The formula simplifies significantly. Since there is only one $k$ value ($k_0 = n$), the inner sum is just $n(1)$, and the multinomial coefficient is $1$. The result is $1/1^n \times (n)^{n-2} = n^{n-2}$, which is Cayley's original formula.

### Special Case: Odd Spanning Trees ($\ell=2$)
If $\ell=2$, then $\zeta = e^{\pi i} = -1$. The roots of unity are $1$ and $-1$. The formula becomes:

$$\tau_2(K_n) = \frac{1}{2^n} \sum_{k=0}^n \binom{n}{k} (2k - n)^{n-2}$$

This matches the formula derived by Feng, Chen, and Wu in 2023 for odd spanning trees, confirming that the new general formula is consistent with existing specialized results.

## Counting Trees in Complete Bipartite Graphs

The complete bipartite graph $K_{m,n}$ consists of two distinct sets of vertices (partitions), where edges only exist between vertices in different sets. Counting $\ell$-congruent spanning trees here requires a dual filtering process—one for each partition. The authors derive the following formula for $\tau_{\ell}(K_{m,n})$:

$$\tau_{\ell}(K_{m,n}) = \frac{1}{\ell^{m+n}} \left[ \sum_{\sum k_j = m, k_j \geq 0} \frac{m!}{k_0! k_1! \cdots k_{\ell-1}!} \left( \sum_{p=0}^{\ell-1} k_p \zeta^p \right)^{n-1} \right] \left[ \sum_{\sum s_q = n, s_q \geq 0} \frac{n!}{s_0! s_1! \cdots s_{\ell-1}!} \left( \sum_{q=0}^{\ell-1} s_q \zeta^q \right)^{m-1} \right]$$

This formula is composed of two symmetrical parts, each extracting the necessary degree congruences for one side of the bipartite graph. 

For the $\ell=1$ case, it simplifies to $m^{n-1} n^{m-1}$, the standard formula for $K_{m,n}$. For $\ell=2$, it yields:

$$\tau_2(K_{m,n}) = \frac{1}{2^{m+n}} \left[ \sum_{k=0}^m \binom{m}{k} (2k - m)^{n-1} \right] \left[ \sum_{s=0}^n \binom{n}{s} (2s - n)^{m-1} \right]$$

This result aligns with previous work by Ge, Yu, and the Xu duo, further demonstrating the unifying power of the $\ell$-congruent framework.

## Significance and Future Directions

The introduction of $\ell$-congruent spanning trees provides a cohesive theory that bridges classical graph results with modern degree-constrained problems. By establishing both existence conditions and enumeration formulas, the authors provide a comprehensive toolkit for analyzing these structures.

One of the unique contributions of this work is the use of the greedy construction algorithm. Not only does it prove existence for the general $\ell$ case, but it also simplifies the constructive proofs for the specific case of odd spanning trees. Furthermore, the use of the roots-of-unity filter demonstrates how complex analysis can solve combinatorial problems involving modular arithmetic.

While the minimum degree condition for existence is proven to be "sharp" for $\ell=2$ (meaning it cannot be improved), the authors note that its sharpness for $\ell \geq 3$ is currently unknown. This remains an open question for future researchers. Additionally, this framework opens the door for studying $\ell$-congruent trees in other classes of graphs, such as multipartite graphs or graphs with specific connectivity properties, and exploring trees where degrees are congruent to values other than one modulo $\ell$.
