## The Challenge of Precise Probabilities in Health Economics

Markov cohort models (MCMs) are standard tools used by researchers to simulate the long-term outcomes of health interventions. By defining a set of health states and the probabilities of moving between them—represented in a transition probability matrix—analysts can project survival, costs, and quality-adjusted life-years (QALYs) over a patient’s lifetime. However, a significant hurdle in this process is that these transition probabilities are often estimated from limited data, such as small clinical trials or observational studies.

Traditionally, MCMs require a single, precise transition matrix. If a clinical trial observes zero events of a specific type (e.g., no deaths in the treatment group during a short follow-up), the model often assumes the probability of that event is exactly zero. This practice conflates a "sampling zero"—where an event simply didn't happen to occur within the study window—with a "structural zero," where the event is physically impossible. Treating uncertain estimates as precise facts can lead to overconfident results and potentially misleading policy recommendations.

The research presented here addresses this by integrating "imprecise probability" into the MCM framework. Instead of relying on one "best guess" matrix, the framework allows for a set of admissible matrices that are all compatible with the available evidence. This approach produces a range of possible outcomes—lower and upper expectations—providing a more robust foundation for decision-making under uncertainty.

## Defining the Imprecise Markov Cohort Model

In a classical MCM, we define a set of health states $S_i$ and a cohort distribution vector $m_t$ at each time step $t$. The movement of the cohort is dictated by the transition matrix $P_t$ according to the equation $m_{t+1} = m_t P_t$. Outcomes, such as costs or health benefits, are assigned to each state via an outcome function $g_t$. The total accumulated outcome over a horizon $T$ is given by $A(P_{0:T-1}) = \sum_{t=0}^T m_t g_t$.

The imprecise extension replaces the single matrix $P_t$ with a non-empty set of admissible transition matrices $\mathcal{P}_t$. An admissible sequence of matrices $P_{0:T-1}$ is then an element of the product set $\mathcal{A} = \mathcal{P}_0 \times \cdots \times \mathcal{P}_{T-1}$. Within this framework, the goal is to find the bounds of the accumulated outcome:

*   The lower expectation: $\underline{A} = \inf A(P_{0:T-1})$
*   The upper expectation: $\overline{A} = \sup A(P_{0:T-1})$

To make this computationally feasible, the research assumes that the sets $\mathcal{P}_t$ are "row-separable." This means that the set of possible transitions out of state $S_i$ is determined independently of the transitions out of any other state. Specifically, for each state $S_i$, there is a compact set $K_{i,t}$ of possible outgoing probability rows $p_{i,t}$. The matrix set is then defined as $P_t = \{P_t : P_{t,i\cdot} \in K_{i,t}, i=1, \ldots, s\}$.

## The Envelope Bellman Recursion

A core contribution of this work is the derivation of an efficient method to calculate the lower and upper expectations. While finding the global minimum or maximum over all possible matrix sequences might seem daunting, the researchers proved that it can be solved using a backward recursion similar to the Bellman equation used in dynamic programming.

First, they define lower and upper transition operators, $\underline{T}_t$ and $\overline{T}_t$. For any outcome function $f \in L(S)$, these operators calculate the worst-case and best-case expected values for the next step:

$$(\underline{T}_t f)(i) = \inf_{p_{i,t} \in K_{i,t}} \sum_{j=1}^s p_{ij,t} f(j)$$

$$(\overline{T}_t f)(i) = \sup_{p_{i,t} \in K_{i,t}} \sum_{j=1}^s p_{ij,t} f(j)$$

Using these operators, the lower and upper values of the total accumulated outcome can be found by working backward from the end of the time horizon $T$:

$$\underline{V}_T = \overline{V}_T = g_T$$

$$\underline{V}_t = g_t + \underline{T}_t \underline{V}_{t+1}$$

$$\overline{V}_t = g_t + \overline{T}_t \overline{V}_{t+1}$$

The final bounds for the cohort starting at time 0 with distribution $m_0$ are simply $m_0 \underline{V}_0$ and $m_0 \overline{V}_0$. This "Envelope Bellman Recursion" ensures that the calculations remain efficient even for long time horizons, as the optimization is performed locally at each state and time step rather than globally over the entire trajectory.

## Data-Driven Imprecision: The Imprecise Dirichlet Model

To apply this framework to real data, researchers need a way to build the sets $K_{i,t}$ from observed transition counts. The paper proposes the Imprecise Dirichlet Model (IDM). 

Suppose we observe $n_{ij}$ transitions from state $i$ to state $j$, with a total of $N_i = \sum_j n_{ij}$ observations from state $i$. Traditional methods would estimate the probability as $p_{ij} = n_{ij} / N_i$. The IDM instead defines a range of probabilities influenced by a prior strength parameter $\alpha > 0$:

$$\underline{p}_{ij} = \frac{n_{ij}}{N_i + \alpha}$$

$$\overline{p}_{ij} = \frac{n_{ij} + \alpha}{N_i + \alpha}$$

The set $K_{IDM,i}$ is formed by all rows where $p_{ij} \geq \underline{p}_{ij}$ and the probabilities sum to one ($\sum_j p_{ij} = 1$). A key advantage of this approach is its handling of "zeros." If $n_{ij} = 0$, the lower bound $\underline{p}_{ij}$ is zero, but the upper bound $\overline{p}_{ij}$ is $\alpha / (N_i + \alpha)$, which is greater than zero. This mathematically acknowledges that the event *could* happen, even if it hasn't been seen yet, preventing the model from becoming artificially certain about rare events.

## Diagnosing Decision Robustness

A vital question for any decision-maker is: "Does this uncertainty actually change the answer?" The paper provides an algebraic "performance-difference identity" to answer this. It quantifies the difference between the outcome of an arbitrary matrix sequence $Q_{0:T-1}$ and a chosen baseline sequence $\hat{P}_{0:T-1}$ (such as the empirical estimates):

$$A(Q_{0:T-1}) - A(Q_{0:T-1}) = \sum_{t=0}^{T-1} m^Q_t (Q_t - \hat{P}_t) \hat{V}_{t+1}$$

This formula reveals three conditions under which imprecision in a transition probability $p_{ij}$ does **not** matter:
1.  If the cohort doesn't spend much time in state $i$ (small $m^Q_t$).
2.  If the difference between the alternative probability and the baseline probability is small.
3.  If the destination states $j$ have very similar future values $\hat{V}_{t+1}(j)$. In this case, it doesn't matter which state the patient transitions into, as the long-term prognosis remains the same.

In health economics, a decision is considered "robust" if the interval for the incremental net monetary benefit (INMB) is entirely on one side of zero. If the interval crosses zero, it indicates that given the current evidence, we cannot confidently say one intervention is better than the other.

## Case Study: Stroke Prevention and PFO Closure

The researchers applied this framework to a study comparing two treatments for patients who have had a cryptogenic stroke: closing a "hole in the heart" (patent foramen ovale or PFO) via surgery versus using medical therapy alone.

In the clinical trials, the group that received PFO closure observed zero recurrent strokes during the follow-up period. A traditional analysis, using these empirical counts, resulted in a positive INMB of \$167 at a willingness-to-pay threshold of $\lambda = \$150,000/\text{QALY}$, suggesting the surgery is cost-effective.

However, when the imprecise framework was applied (using the IDM with $\alpha=2$), the results changed significantly. The INMB was no longer a single number but an interval: [-\$1,387, \$1,618]. Because this interval contains zero, the decision to favor PFO closure is shown to be non-robust. The "zero strokes" in the trial might simply be a result of the small sample size rather than perfect effectiveness.

![figure-2-probability-of-making-a-wrong-decision-versus-sample-size-for-different-models](https://paper-assets.alphaxiv.org/figures-normalized/figures/2606.25716v1/img-1.jpeg)

A simulation study further illustrated this point. As shown in {fig:figure-2-probability-of-making-a-wrong-decision-versus-sample-size-for-different-models}, when data is sparse (low patient-years at risk $N$), traditional point estimates frequently lead to "wrong" decisions—confident recommendations that turn out to be incorrect when the true underlying probability is known. In contrast, the IDM analysis rarely makes a confidently wrong decision. Instead, it "abstains" by providing an interval that crosses zero, signaling to the decision-maker that more evidence is needed. As the sample size $N$ increases, the imprecision shrinks at a rate of $O(\alpha/N)$, and the IDM interval eventually converges to the correct, robust decision.

## Conclusion and Policy Implications

By providing a rigorous way to calculate the lower and upper bounds of outcomes in Markov cohort models, this research offers a tool for more transparent health economic evaluations. It moves the conversation away from "what is the best guess?" toward "is the evidence strong enough to support this choice?"

The use of the Imprecise Dirichlet Model and the Envelope Bellman Recursion allows analysts to handle sparse data and rare events without making unjustified assumptions about zero probabilities. This framework does not replace existing models but extends them, allowing researchers to report a range of expectations that more accurately reflects the limits of the available data. Ultimately, this leads to more robust policy recommendations and a clearer understanding of the risks associated with medical decision-making.
