## The Challenge of Selecting Flat Clusterings

Hierarchical clustering is a cornerstone of exploratory data analysis, providing a multi-scale view of data structure through nested groupings. Rather than producing a single partition, these methods generate a tree, or dendrogram, representing how data points merge at different levels of similarity. While this tree is rich in information, many downstream applications—ranging from gene expression analysis to customer segmentation—require a single "flat" clustering solution.

Historically, extracting this flat solution has relied on global, horizontal cuts across the tree. A user might decide to cut the tree at a specific height or based on the number of clusters desired. However, such horizontal cuts are inherently limited because they assume that the optimal clusters all exist at the same level of granularity. In real-world data, meaningful clusters often appear at different scales; some may be dense and small, while others are sparse and large.

*{fig:a-comparison-of-different-clustering-interpretations-of-the-same-dataset}: Different hierarchical levels can yield varying but equally valid clusterings depending on the desired granularity.*

To move beyond horizontal cuts, optimization-based frameworks like the Framework for Optimal Selection of Clusters (FOSC) were developed. FOSC treats cluster selection as an optimization problem: find a set of non-overlapping nodes in the tree that maximize a chosen quality metric (e.g., cluster stability or modularity). While FOSC is efficient, it historically provided only one "best" solution and lacked the ability to strictly control how many clusters were returned. FOSC-X addresses these gaps by extending the framework to provide the top-$M$ highest-scoring clusterings while allowing for precise constraints on the number of clusters.

## The FOSC-X Framework: Multi-Solution Extraction

One of the central realizations behind FOSC-X is that the "correct" clustering is often subjective. A single optimization score may not capture all the nuances of a dataset. By providing the top-$M$ alternative solutions, FOSC-X allows researchers to explore different interpretations of the data that are nearly as good as the global optimum but might offer better semantic meaning.

The extraction process utilizes a bottom-up dynamic programming approach. At every node $C_i$ in the hierarchy, the algorithm maintains a set of candidate partial clusterings, denoted as $S_{\text{topM}}(C_i)$. For each node, two choices are evaluated:
1. **Selection:** Choose the current node $C_i$ itself as a cluster, with quality score $q(C_i)$.
2. **Expansion:** Decompose the node into its children and combine the best partial solutions from those children.

In the unconstrained case, combining child solutions involves a Minkowski sum of the top-$M$ sets of all children. This process effectively considers all $M^{|ch(C_i)|}$ combinations of the best child clusterings, though it only retains the top $M$ overall to keep the process efficient. This ensures that by the time the algorithm reaches the root of the tree, it has identified the $M$ globally highest-scoring non-overlapping partitions of the data.

## Incorporating Granularity Constraints

In many practical settings, an unconstrained optimization might produce far too many small clusters or just one giant one. Users often have a target range in mind for the number of clusters, denoted as $[k_{\min}, k_{\max}]$. However, adding these constraints breaks the "optimal substructure" property that simple dynamic programming relies on. A locally optimal choice for a subtree might lead to a total cluster count that violates the global constraints.

FOSC-X resolves this by calculating structural bounds for each node:
* **Lower Bound ($LB_{C_i}$):** The minimum number of clusters that *must* be chosen outside the current subtree to eventually form a complete, valid partition of the dataset.
* **Upper Bound ($UB_{C_i}$):** The maximum number of clusters that *can* be chosen outside the current subtree.

Using these bounds, every candidate partial clustering $z_{C_i}$ is assigned a "feasible completion interval" $[\ell(z_{C_i}), u(z_{C_i})]$. This interval defines exactly how many additional clusters can be selected elsewhere to satisfy the user's constraints:

$$\ell(z_{C_i}) = \max(LB_{C_i}, k_{\min} - |z_{C_i}|)$$
$$u(z_{C_i}) = \min(UB_{C_i}, k_{\max} - |z_{C_i}|)$$

A candidate is only considered valid if $\ell \leq u$, meaning there is at least one way to complete the clustering within the allowed range.

## Dominance Pruning for Efficiency

Tracking every possible cluster count combination would lead to a combinatorial explosion, making the algorithm unusable for large datasets. FOSC-X introduces a "dominance pruning" strategy to maintain efficiency. 

A partial clustering is pruned if it is "dominated" by other better-scoring candidates that cover the same possible cluster counts. Specifically, a candidate is retained only if it offers a high score for at least one specific cluster count that hasn't already been satisfied by $M$ better solutions. 

![a-schematic-of-the-cluster-tree-with-precomputed-bounds-and-quality-scores](https://paper-assets.alphaxiv.org/figures-normalized/figures/2606.18972v1/img-5.jpeg)
*{fig:a-schematic-of-the-cluster-tree-with-precomputed-bounds-and-quality-scores}: The hierarchical structure annotated with quality scores and feasibility bounds used for dynamic programming.*

This strategy ensures that the algorithm's time complexity remains linear, $O(n)$, with respect to the number of data points when the number of solutions $M$ and the maximum cluster count $k_{\max}$ are treated as constants. Specifically, the unconstrained extraction runs in $O(N M^2 \log M)$ time, while the constrained version runs in $O(N M^2 k_{\max} \log(M k_{\max}))$.

## Empirical Performance and Validation

The authors tested FOSC-X on a massive set of 2,100 synthetic datasets, comparing its ability to recover ground-truth clusters against traditional single-solution methods. They evaluated the results using Adjusted Mutual Information (AMI), a metric that measures the similarity between the extracted clusters and the true data labels.

The results highlights several key findings:
1. **The Power of Multi-Solution Exploration:** The versions of FOSC-X that returned the top-5 or top-10 solutions consistently outperformed the standard $M=1$ baseline. This confirms that the most semantically "correct" clustering is often not the single highest-scoring one but is frequently found within the top few alternatives.
2. **Effective Granularity Control:** Using "relaxed" constraints (e.g., $k^* \pm 3$ where $k^*$ is the true number of clusters) allowed the framework to guide the optimization away from fragmented or overly coarse solutions, leading to higher AMI scores.
3. **Computational Superiority:** Compared to DynaCut, an existing method for fixed-$k$ extraction, FOSC-X demonstrated much better scaling. While DynaCut is theoretically efficient, its practical runtime often scales as $O(k^2)$, whereas FOSC-X exhibited sub-linear growth in $k$ due to the effectiveness of its pruning strategy.

## Significance for Researchers

FOSC-X represents a significant step forward in the utility of hierarchical clustering. By providing multiple high-quality solutions and flexible control over cluster counts, it transforms a rigid optimization task into a powerful tool for interactive data exploration. 

The framework is agnostic to the specific clustering algorithm used—it works equally well with density-based hierarchies like HDBSCAN* or linkage-based ones like Ward’s method. So long as a quality metric can be calculated for each node in a way that is additive, FOSC-X can optimize it. This versatility makes it applicable to a wide array of domains, from biological taxonomy to modern machine learning pipelines, where understanding the multi-scale structure of data is essential. 

Ultimately, FOSC-X acknowledges the inherent ambiguity in data analysis. Rather than forcing a single, potentially flawed perspective, it empowers the researcher to see the "best" interpretations the data has to offer.
