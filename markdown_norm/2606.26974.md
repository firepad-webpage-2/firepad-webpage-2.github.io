## The Complexity of Morphological Shape Evolution

Understanding how physical forms—such as the delicate patterns of a butterfly's wing or the robust structure of a bird's beak—change over evolutionary time is a central challenge in biology. This field, known as phylogenetic inference, traditionally relies on genetic data to map the relationships between species. However, interpreting the evolution of "shape" itself requires sophisticated mathematical models that can handle high-dimensional geometry while accounting for the common ancestry of the organisms being studied.

![reconstructed-ancestral-wing-shape](https://paper-assets.alphaxiv.org/figures-normalized/figures/2606.26974v1/figures/butterflies-large-male-root.png)
*{fig:reconstructed-ancestral-wing-shape}: Posterior samples of the reconstructed ancestral wing shape at the root of a butterfly phylogeny, illustrating the range of probable forms for the common ancestor of the studied lineages.*

In modern morphometrics, researchers represent shapes using "landmarks"—specific, biologically meaningful points on an organism. A complex shape might require hundreds of landmarks, creating a high-dimensional dataset where the position of one point is often strongly correlated with its neighbors. Modeling how these points move and shift across a phylogenetic tree is computationally demanding, particularly when trying to ensure the models remain biologically realistic (for example, ensuring that parts of a wing do not "cross over" each other during simulated evolution).

## The Challenge of Non-Linear Stochastic Models

To accurately capture shape evolution, researchers use stochastic processes—mathematical models that describe systems evolving over time with inherent randomness. Specifically, diffusion processes are often used to model landmark movement. A significant difficulty arises because these processes are frequently non-linear; the way a shape changes at any given moment (its covariance) depends on its current state.

In a phylogenetic context, we want to calculate the "likelihood" of observing the shapes we see today given a specific evolutionary model and tree structure. For simple, linear models, this can be done efficiently using classical algorithms like Felsenstein’s pruning algorithm. However, for the non-linear models required for realistic shape dynamics, the mathematical "messages" passed along the branches of the tree—representing the probability of certain ancestral states—become "intractable." This means they cannot be solved exactly in a reasonable amount of time.

To address this, a framework called Backward Filtering Forward Guiding (BFFG) was developed. BFFG approximates these intractable messages using simpler forms (typically Gaussian distributions) to estimate the likelihood and simulate ancestral states. While theoretically powerful, BFFG has historically lacked a software implementation that could scale to large datasets, such as trees with hundreds of species and shapes with many landmarks.

## Introducing Hyperiax: A Scalable Tree Computation Library

The researchers developed **Hyperiax**, an open-source Python library designed to bridge the gap between complex evolutionary models and large-scale data. Hyperiax is built on top of JAX, a high-performance numerical computing library that supports just-in-time (JIT) compilation, automatic differentiation, and hardware acceleration via GPUs and TPUs.

Hyperiax provides a specialized infrastructure for "tree sweeps"—algorithms that traverse a phylogenetic tree to calculate values at every node. By optimizing these traversals, Hyperiax allows the BFFG framework to be applied to datasets that were previously too large to process.

### Core Architecture and Abstractions

The library is organized around several key objects that separate the structure of the tree from the data it contains:

1.  **Topology:** This object stores the "skeleton" of the tree—the parent-child relationships and the order in which nodes should be visited.
2.  **Tree:** This is a container that maps data (like shape coordinates or model parameters) onto a specific Topology. Because it uses JAX’s immutable data structures, any operation on a Tree produces a new Tree, ensuring consistency in complex computations.
3.  **Sweeps:** Hyperiax uses decorators to define how information moves through the tree:
    *   `@up`: Defines "postorder" traversals, moving from the leaves (modern species) toward the root (ancestors). This is used for "filtering" or gathering information.
    *   `@down`: Defines "preorder" traversals, moving from the root toward the leaves. This is used for "guiding" or simulating data.

The modular design allows biologists to write code that looks like mathematical equations, while the library handles the underlying complexities of memory management, batching, and parallel execution.

## The BFFG Framework in Hyperiax

The Backward Filtering Forward Guiding (BFFG) framework implemented in Hyperiax functions in two main stages to perform inference:

### Backward Filtering (The Up Sweep)
Starting from the observed shapes at the tips of the tree, the algorithm moves toward the root. At each step, it calculates an "information filter"—a summary of the evidence from the descendants regarding the ancestral state. Because the true probability distributions are complex and non-linear, Hyperiax uses Gaussian approximations to keep the math tractable.

### Forward Guiding (The Down Sweep)
Once the root is reached, the algorithm moves back down toward the leaves. It simulates the evolutionary process along each branch, but this simulation is "guided" by the information gathered during the upward pass. This ensures that the simulated ancestral states are consistent with the observed data at the tips.

For continuous-time models, the evolution is modeled as a Stochastic Differential Equation (SDE) of the form:
$$
dx_t = f(x_t, t)dt + L(x_t, t)dw_t
$$
where $x_t$ is the shape at time $t$, $f$ describes the deterministic "drift," and $L$ describes the "diffusion" or random noise. Hyperiax calculates these terms efficiently, even when the diffusion matrix $L$ depends on the current shape $x_t$.

## Empirical Demonstration: Butterfly Wings and Avian Beaks

The authors demonstrated the power of Hyperiax by applying it to two significant biological datasets, reaching a scale of computation far beyond previous attempts.

### 2D Butterfly Wing Landmarks
The team analyzed 118 two-dimensional landmarks on the wings of butterflies. The phylogeny involved 425 observed species, resulting in a total tree size of 850 nodes. 

![butterfly-phylogeny](https://paper-assets.alphaxiv.org/figures-normalized/figures/2606.26974v1/figures/butterflies-large-male-tree.png)
*{fig:butterfly-phylogeny}: The large-scale phylogenetic tree of butterflies used in the study, containing over 400 species.*

Using a Metropolis-Hastings Markov Chain Monte Carlo (MCMC) approach enabled by Hyperiax, they inferred several key evolutionary parameters:
*   **Diffusivity ($k_{\alpha}$):** This measures how quickly the shape changes. The posterior mean was $0.134$, with a $95\%$ credible interval of $[0.106, 0.167]$.
*   **Spatial Correlation ($k_{\sigma}$):** This measures how much the movement of one landmark affects its neighbors. The posterior mean was $0.212$, with an interval of $[0.178, 0.242]$.
*   **Observation Noise ($\sigma^2_{\text{obs}}$):** The variance in the measurement was estimated at $1.25 \times 10^{-3}$.

The convergence of the model was verified using the Gelman-Rubin statistic ($\hat{R}$), which reached $1.002$, indicating highly reliable results across multiple independent simulation chains.

![butterfly-parameter-traces](https://paper-assets.alphaxiv.org/figures-normalized/figures/2606.26974v1/figures/butterflies-large-male-trace.png)
*{fig:butterfly-parameter-traces}: MCMC trace plots for the butterfly wing parameters $k_{\alpha}$ and $k_{\sigma}$, showing stable convergence across four independent chains.*

### 3D Avian Beak Landmarks
In a second test, the researchers used 79 three-dimensional landmarks from avian beaks across a tree of 348 species (696 nodes). 

![avian-beak-landmarks](https://paper-assets.alphaxiv.org/figures-normalized/figures/2606.26974v1/figures/beaks-large-leaves.png)
*{fig:avian-beak-landmarks}: Visualization of the 3D landmark data points sampled from avian beak specimens.*

The inferred parameters for the bird beak model were:
*   **Diffusivity ($k_{\alpha}$):** $0.113$ (interval $[0.080, 0.157]$).
*   **Spatial Correlation ($k_{\sigma}$):** $0.152$ (interval $[0.121, 0.194]$).
*   **Observation Noise ($\sigma^2_{\text{obs}}$):** $0.408 \times 10^{-3}$.

The $\hat{R}$ value of $1.011$ confirmed that the library could handle 3D data on large trees with consistent accuracy.

## Significance for Evolutionary Biology

Hyperiax represents a move toward more realistic and scalable models in evolutionary biology. By overcoming the computational barriers of the BFFG framework, it allows researchers to ask deeper questions about the history of life:

1.  **High-Resolution Ancestry:** Researchers can now reconstruct ancestral forms (like the root wing shape in {fig:reconstructed-ancestral-wing-shape}) with greater detail, incorporating the complex correlations between different parts of a physical structure.
2.  **Quantifying Evolutionary Rates:** The ability to precisely estimate diffusivity and spatial correlation help biologists understand whether certain traits evolve faster than others or if specific physical constraints (like bone structure) limit the range of possible shapes.
3.  **General Utility:** While the study focuses on shape, the "tree sweep" architecture of Hyperiax is general. It can be used for any biological data that follows a tree structure, including gene expression levels, geographical ranges, or epidemiological data.

By providing an open-source, JAX-powered toolkit, Hyperiax makes advanced stochastic modeling accessible to the broader scientific community, facilitating a more rigorous and detailed exploration of morphological evolution across the tree of life.
