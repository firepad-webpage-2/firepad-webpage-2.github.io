## Principles of Active Noise Control and the Fusion Framework

Active Noise Control (ANC) is a technique used to reduce unwanted noise by generating an "anti-noise" signal. This anti-noise signal is designed to have the same amplitude as the original noise but with the opposite phase, leading to destructive interference at a specific location, such as the ear of a headphone user. The acoustic environment of an ANC system is typically described by two paths: the primary path, which represents the acoustic propagation from the noise source to the error microphone, and the secondary path, which represents the propagation from the control speaker to the error microphone.

Traditional ANC systems rely on adaptive filters that continuously update their parameters to track changes in the noise or the acoustic environment. While flexible, these adaptive systems can be prone to instability and slow convergence. In contrast, fixed-parameter controllers use pre-optimized settings, offering high stability and instant response. However, fixed-parameter systems often suffer from performance degradation when the actual acoustic path or noise type differs from the conditions used during training.

![framework-of-the-feedback-guided-dnn-based-controller-fusion](https://paper-assets.alphaxiv.org/figures-normalized/figures/2608.14061v1/framework.png)
*{fig:framework-of-the-feedback-guided-dnn-based-controller-fusion}: The proposed framework combines a stable WaveNet-based feedforward controller with a feedback-guided Mixture-of-Experts (MoE) module. The outputs are fused to generate the final anti-noise signal.*

The proposed framework addresses this trade-off by using a hybrid architecture. It consists of two parallel branches: a fixed feedforward WaveNet controller and a feedback-guided Mixture-of-Experts (MoE) module. Let $x(n)$ be the reference noise signal, $y(n)$ be the final generated control signal, $d(n)$ be the primary noise reaching the error microphone, and $e(n)$ be the residual error signal measured by the microphone. The relationship between the two branches is expressed through a weighted summation:

$$y(n) = \alpha y_W(n) + (1 - \alpha) y_M(n)$$

where $y_W(n)$ is the output of the WaveNet branch, $y_M(n)$ is the output of the MoE branch, and $\alpha$ is a fusion coefficient that determines the contribution of each component. By combining a globally optimized neural network with a set of specialized experts, the system aims to maintain stability while dynamically adapting to specific acoustic conditions.

## The Feedforward WaveNet Branch

The first component of the system is a Deep Neural Network (DNN) based on the WaveNet architecture. WaveNet is a generative model originally designed for audio waveforms, and its causal structure makes it suitable for real-time ANC tasks. In this framework, the WaveNet branch serves as a reliable baseline controller. It is trained on the entire set of available noise and acoustic path data to find a set of parameters that performs well on average across all scenarios.

The core of the WaveNet branch consists of a series of residual blocks. Each block employs dilated one-dimensional convolutions, which allow the network to have a large receptive field (capturing long-term temporal dependencies) without requiring a massive number of parameters. Each block also contains a gated activation unit, which is defined as:

$$z = \tanh(W_{f,k} * a) \odot \sigma(W_{g,k} * a)$$

In this equation, $W_{f,k}$ and $W_{g,k}$ represent the weights of the filters in the $k$-th layer, $*$ denotes the convolution operation, $\odot$ represents element-wise multiplication, and $\sigma(\cdot)$ is the sigmoid function. This gating mechanism allows the network to model complex non-linear relationships between the reference noise and the required anti-noise. Because the parameters of the WaveNet branch are fixed after training, it provides a stable foundation that prevents the overall system from diverging, even if the acoustic environment changes rapidly.

## Feedback-Guided Mixture-of-Experts (FG-MoE)

While the WaveNet branch provides stability, it may not provide the optimal level of noise reduction for a specific, unique acoustic path. The Feedback-Guided Mixture-of-Experts (MoE) module is designed to bridge this gap. This module consists of a set of pre-trained expert filters and a gating network that selects the best combination of these experts in real-time.

A unique feature of this approach is the use of feedback signals in the gating network. Most existing systems only look at the reference signal $x(n)$ to decide which filter to use. However, the reference signal only characterizes the incoming noise, not the state of the acoustic path itself. The proposed gating network takes three inputs: the reference signal $x(n)$, the current control signal $y(n)$, and the previous residual error signal $e(n-1)$. The use of the previous error signal is necessary for causality, as the effect of the current control signal $y(n)$ on the error $e(n)$ cannot be observed until after it has propagated through the physical secondary path.

The gating network processes these signals to calculate fusion weights $\beta_i(n-1)$ for $N$ different experts. The output of the MoE branch is then calculated as:

$$y_M(n) = w_M(n)^T x_L(n)$$

where the combined filter coefficients $w_M(n)$ are a weighted sum of the individual expert coefficients $w_i$:

$$w_M(n) = \sum_{i=1}^{N} \beta_i(n-1)w_i$$

Each expert filter $w_i$ is a 2048-tap Finite Impulse Response (FIR) filter that has been specialized for a specific acoustic path. By monitoring the error and control signals, the gating network can detect if the current expert selection is failing to cancel the noise effectively and adjust the weights to better match the actual acoustic environment.

## Frequency-Aware Loss and Staged Training

Training a complex fusion system requires a specialized strategy to ensure that each component fulfills its role. The authors employ a staged training approach. In the first stage, the WaveNet branch is trained on all data to establish the baseline. In the second stage, the FIR experts are trained independently, each specialized to a specific acoustic path in the training set. In the third stage, the WaveNet and experts are frozen, and only the gating network is trained to learn how to fuse them based on real-time feedback.

The performance of the system is guided by a frequency-aware loss function $L_{ANC}$, which is designed to balance noise reduction and high-frequency stability. The loss function is composed of three parts:

$$L_{ANC} = L_{NR} + \lambda L_{RB} + L_{NMSE}$$

$L_{NR}$ represents the mean noise reduction in the low-to-mid frequency range (50 Hz to 5 kHz). $L_{RB}$ represents "rebound," which refers to unwanted noise amplification at higher frequencies (typically above 1 kHz). $\lambda$ is a weighting factor that penalizes the model if it achieves noise reduction at the cost of creating significant high-frequency artifacts. Finally, $L_{NMSE}$ is the broadband normalized mean square error, which ensures overall energy reduction. During the final stage of training, an additional cross-entropy loss $L_{cls}$ is added:

$$L_{total} = L_{ANC} + \gamma L_{cls}$$

where $\gamma$ is a scaling factor. $L_{cls}$ provides a supervised signal to the gating network, helping it learn which expert corresponds to which acoustic path, while $L_{ANC}$ refines the fusion weights to maximize actual performance.

## Real-Time Performance and Computational Efficiency

For practical applications like ANC headphones, the system must operate in real-time with minimal latency and computational cost. The framework is designed for sample-wise streaming inference, meaning it processes each audio sample as it arrives. 

To make the system more efficient on embedded hardware, the researchers implemented a peak-MAC (Multiply-Accumulate operations) optimization. In neural networks, computational load is often unevenly distributed across time. By spreading the calculation of the MoE weights and other operations across multiple sampling points, the researchers reduced the peak computational demand by approximately 59%, making it easier to integrate into low-power chips.

## Significance and Future Implications

This research presents a robust method for managing the trade-offs in Active Noise Control. By moving beyond reference-only selection and incorporating feedback from the control and error signals, the system achieves a higher degree of adaptability to the physical acoustic environment than previous DNN-based fixed-parameter controllers. 

The framework's ability to remain stable while handling unseen acoustic paths makes it a viable candidate for high-end consumer electronics. Moreover, the optimization of computational load ensures that these advanced deep learning techniques can be deployed on the limited hardware found in portable devices. Future work could involve expanding the number of experts or exploring more complex neural architectures for the experts themselves, potentially leading to even greater noise reduction in highly dynamic environments. The principles established here—combining stable baseline neural networks with feedback-guided experts—may also find application in other fields of real-time control, such as robotics or active vibration damping.
