## Foundations of Policy Evaluation and TD Learning

Policy evaluation is a core task in reinforcement learning (RL), serving as the process of estimating the value function of a specific decision-making rule. The value function represents the expected cumulative reward an agent will receive starting from a given state. In large-scale applications where the state space is continuous or prohibitively large, researchers typically employ linear function approximation. This approach models the value function as a linear combination of features, reducing the problem to estimating a vector of weights.

Temporal-Difference (TD) learning is the standard streaming algorithm for this task. It updates its estimates iteratively as new data arrives, rather than waiting for an entire episode to conclude. In the context of on-policy linear TD(0), the update rule for the weight vector at time $t$ with a constant stepsize $\alpha$ is given by:

$$\theta_{\alpha,t+1} = (I - \alpha A_{t+1})\theta_{\alpha,t} + \alpha b_{t+1}$$

In this recursion, $I$ is the identity matrix, and the pair $(A_{t+1}, b_{t+1})$ represents the stochastic update information derived from the environment's state transitions and rewards. The goal is to estimate the projected Bellman solution $\theta^*$, which satisfies the system $\bar{A}\theta^* = \bar{b}$, where $\bar{A} = E[A_t]$ and $\bar{b} = E[b_t]$.

While TD learning is well-understood in terms of convergence, performing statistical inference—such as constructing confidence intervals—remains challenging. In realistic scenarios, data is collected along a single Markovian trajectory, meaning that $A_t$ and $b_t$ are not independent over time. Furthermore, constant-stepsize TD learning introduces a persistent bias: the iterates fluctuate around a stationary mean $\theta_\alpha$ that does not coincide with the true solution $\theta^*$. This paper provides a framework to address these issues using path-level theory and self-normalization.

## The Challenge of Constant-Stepsize Bias

A fundamental property of the constant-stepsize TD recursion is that it does not converge to a single point. Instead, it converges in distribution to a unique stationary law. The mean of this law, $\theta_\alpha$, is a function of the stepsize $\alpha$. Crucially, $\theta_\alpha$ is generally not equal to $\theta^*$. As $\alpha$ increases, the algorithm learns faster but the distance between $\theta_\alpha$ and $\theta^*$ (the stationary bias) grows. Conversely, as $\alpha$ decreases, the bias shrinks, but the convergence to the stationary distribution becomes slower.

Traditional inference methods often assume that the estimator is centered at the target of interest. If one constructs a confidence interval centered at the empirical average of the iterates, the interval will eventually cover $\theta_\alpha$ with high probability, but it might completely miss $\theta^*$. This discrepancy is particularly problematic when $\alpha$ is chosen to be large for faster initial learning.

The existing literature typically deals with this by using decreasing stepsizes, which ensures that the bias vanishes asymptotically. However, constant stepsizes are often preferred in practice for their simplicity and ability to track non-stationary environments. The authors of this work address this trade-off by explicitly modeling the bias and providing tools to mitigate it, allowing for valid inference even when the target is slightly shifted.

## Richardson–Romberg Extrapolation for Bias Reduction

To bridge the gap between $\theta_\alpha$ and $\theta^*$, this work utilizes Richardson–Romberg (RR) extrapolation. The core idea is to run multiple TD recursions in parallel using different constant stepsizes, all driven by the same sequence of Markovian data $(A_t, b_t)$. 

Suppose we use $L$ different stepsizes $\alpha_\ell = a_l \alpha$, where $a_\ell$ are fixed nodes. We can then form a weighted combination of the resulting iterates:

$$\vartheta_t = \sum w_\ell \theta_t^{(\ell)}$$

By carefully selecting the weights $w_\ell$ to satisfy specific cancellation conditions (specifically $\sum w_\ell = 1$ and $\sum w_\ell a_\ell^j = 0$ for $j=1, \dots, q_{RR}$), the resulting extrapolated estimator $\vartheta_t$ has a stationary mean $\theta_{RR,\alpha}$ where the bias is significantly reduced. Specifically, the distance between the RR target and the true solution is:

$$\|\theta_{RR,\alpha} - \theta^*\| = O(\alpha^{q_{RR}+1})$$

This higher-order bias reduction allows the researcher to use relatively large stepsizes while keeping the target shift negligible relative to the statistical fluctuations of the algorithm. This method is computationally efficient because it only requires running a few additional linear updates in parallel on the same data stream.

## Self-Normalized Inference and Path Theory

Even with the bias reduced, constructing confidence intervals for a linear contrast $R\theta^*$ (where $R$ is a vector or matrix defining the states of interest) requires knowing the variance of the estimator. In the Markovian setting, this is not just the simple variance of the rewards, but a complex "long-run covariance" that accounts for the serial dependence in the state transitions.

Estimating this long-run covariance typically involves "plug-in" estimators that require tuning parameters, such as the bandwidth in a kernel estimator or the block length in a batch-means approach. These parameters are notoriously difficult to select in an online setting. The authors bypass this by using a self-normalization (SN) approach.

The SN method uses a Brownian-bridge-based normalizer. For a generic sequence $X_t$, the self-normalizer $\hat{V}_{SN,n}$ is defined using partial sums $S_s = \sum_{t=1}^s X_t$ and the global average $\bar{X}_n = S_n/n$:

$$\hat{V}_{SN,n} = \frac{1}{n^2} \sum_{s=1}^n (S_s - s \bar{X}_n)(S_s - s \bar{X}_n)^\top$$

The paper proves a Functional Central Limit Theorem (FCLT) showing that the path of TD iterates, when properly scaled, converges weakly to a Brownian motion. Because the same long-run covariance matrix appears in both the fluctuations of the estimator and the fluctuations of the self-normalizer $\hat{V}_{SN,n}$, it cancels out in the limit. This results in an asymptotically pivotal statistic $T_{SN,n}$ that follows a known distribution involving functionals of a Brownian bridge, allowing for the construction of confidence intervals without any nuisance parameter estimation.

## Horizon-Indexed Designs for the Projected Bellman Solution

While the RR method provides inference for a biased-reduced target $\theta_{RR,\alpha}$, practitioners often want guarantees directly for the true projected Bellman solution $\theta^*$. The paper introduces the "horizon-indexed" design to achieve this. In this regime, the stepsize $\alpha_n$ is constant during a single run of length $n$, but it is chosen to depend on the terminal horizon $n$ such that $\alpha_n \to 0$ as $n \to \infty$.

By setting $\alpha_n = n^{-\nu}$ for a specific range of $\nu$, the authors identify a window where:
1. The stationary bias $\theta_{RR,n} - \theta^*$ vanishes fast enough that it does not affect the asymptotic distribution.
2. The initial starting point of the recursion (initialization bias) is forgotten quickly enough.
3. The multiplicative noise component of the TD updates (which makes Markovian analysis hard) becomes negligible.

For a specific RR order $q_{RR}$, the theory identifies a feasible range for the exponent $\nu$. For example, if the initialization is deterministic, valid inference for $\theta^*$ is possible if $1/(2(q_{RR}+1)) < \nu < \min(1/2, 1-2/p)$ where $p$ relates to the moments of the driving process. This allows the self-normalized statistic to be centered exactly at $\theta^*$, providing direct uncertainty quantification for the optimal linear weights.

## Algorithmic Implementation and Performance

One of the most practical contributions of the work is an online algorithm (Algorithm 1) for computing the self-normalized statistics. Since the normalizer $\hat{V}_{SN,n}$ involves a sum of terms dependent on the cumulative mean $\bar{X}_n$, a naive implementation would require $O(n)$ memory. However, the authors show that for any linear contrast $R$, the statistic can be updated in a single pass with $O(1)$ memory relative to the trajectory length.

The researchers evaluated their method on standard RL benchmarks, including FrozenLake and Garnet MDPs. Their experiments confirmed several key theoretical predictions:
* **Target Shift Reduction:** RR extrapolation reduced the bias relative to $\theta^*$ by over 30 times in some Garnet configurations compared to standard constant-stepsize TD.
* **Coverage Reliability:** The RR-SN approach consistently achieved near-nominal coverage (e.g., 95%) without the sensitivity to batch sizes seen in traditional batch-means methods.
* **Initialization Sensitivity:** In the horizon-indexed regime, the study found that while the method is asymptotically robust, finite-sample performance for $\theta^*$ is significantly improved by using a small "warm-start" period to wash out the effects of the initial weight vector.

Overall, the framework provides a robust toolkit for researchers needing reliable, online uncertainty estimates for value functions in complex, dependent environments. By combining Richardson–Romberg extrapolation with self-normalized path theory, it bridges the gap between high-speed learning with constant stepsizes and the rigorous requirements of statistical inference.
