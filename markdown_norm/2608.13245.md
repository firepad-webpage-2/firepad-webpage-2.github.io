## The Shift Toward Intelligent Cooperative Perception

Cooperative Perception (CP) is a fundamental capability for future autonomous systems, such as self-driving vehicles, drones, and smart factory robots. By sharing sensory data between multiple agents, CP allows these systems to overcome individual limitations like occlusions (blind spots) and limited sensor ranges. However, transmitting high-resolution visual data over wireless networks is challenging. Traditional communication systems rely on error-checking and retransmission protocols (like ARQ) to ensure every bit is received perfectly. In high-density scenarios or poor wireless conditions, these protocols lead to significant latency and jitter, which can be catastrophic for real-time safety applications.

The research introduces the Synesthesia of Machines (SoM)-driven Masked Token Model (SoM-MTM) to address these issues. Guided by the SoM paradigm—which promotes the native integration of sensing and communication—this work moves away from bit-perfect transmission. Instead, it treats communication channels as lossy and leverages artificial intelligence to "reason" through missing information. Rather than asking for retransmissions when a packet is lost, the system uses the context of the successfully received data to reconstruct the missing parts of the visual features.

## The "Token as Packet" Paradigm

A central contribution of this work is the "token as packet" modeling approach. Traditional visual encoders, particularly those based on Transformers, break down an image into smaller units called patches or tokens. In SoM-MTM, each high-level perceptual token $Z_i$ in a sequence $Z = \{Z_1, Z_2, \dots, Z_N\}$ is treated as an individual data packet for transmission.

This modeling choice aligns visual representation directly with the mechanics of wireless communication. When a wireless channel experiences interference or fading, specific packets are lost. By mapping one token to one packet, the loss of a packet corresponds directly to the loss of a specific spatial region's feature information. The status of these packets is tracked using a binary mask $M$, where $M_i = 1$ indicates a successfully received token and $M_i = 0$ indicates a loss.

The efficiency of this system is quantified by the compression ratio $CR$, defined as the ratio of the transmitted latent features to the original raw image data:
$$CR = \frac{N \cdot d}{H_0 \cdot W_0 \cdot k}$$
where $N$ is the number of tokens, $d$ is the feature dimension, $H_0 \times W_0$ is the image resolution, and $k$ represents the bit-depth of the raw data. By transmitting compressed tokens instead of raw pixels, the system significantly reduces the required communication bandwidth while remaining robust to the inevitable loss of some packets.

## Architecture: The Masked Token Model

At the heart of the system is the SoM-MTM module, a plug-and-play enhancement located at the receiving "task-node." This module is designed to refine the received features before they are used for reconstruction or downstream tasks like classification.

The architecture utilizes a Swin Transformer as its backbone. The Swin Transformer is chosen for its hierarchical structure and the use of shifted windows, which allow the model to learn spatial correlations effectively. When tokens are lost during transmission, the receiver fills these gaps with a learnable "mask token" $z_{mask}$. The input to the enhancement model $F_{in}$ is thus a mixture of received features $\tilde{F}$ and mask tokens:
$$F_{in} = \tilde{F} \odot M + z_{mask} \odot (1 - M)$$

![swin-mtm-backbone](https://paper-assets.alphaxiv.org/figures-normalized/figures/2608.13245v1/Swin-MTM.png)
*{fig:swin-mtm-backbone}: The architecture of the SoM-MTM enhancement module, featuring stacked 2D Swin Transformer layers and a token forcing strategy.*

As the tokens pass through the layers of the Swin Transformer, the model uses the surrounding, successfully received tokens to predict and refine the information in the missing (masked) positions. A unique "token forcing" strategy is applied at the end: tokens that were known to be received perfectly are directly copied from the input to the final output, ensuring that the model does not introduce unnecessary distortion to reliable data.

## Leveraging Communication Priors with ERMoE

A significant departure from standard AI models is how SoM-MTM utilizes communication-layer information. In a typical wireless receiver, the system knows exactly which packets failed error-checking. SoM-MTM exploits this packet status mask $M$ as a "prior" through a novel mechanism called External Routing Mixture-of-Experts (ERMoE).

In a standard Mixture-of-Experts (MoE) setup, the model learns a "router" that decides which internal "expert" (a sub-network) should process a given token based on the token's features. This adds computational complexity and can be difficult to train. ERMoE simplifies this by using the external packet mask $M_i$ to perform the routing.

### ERMoE in Feed-Forward Networks (FFN)
In the FFN layers, each token is routed to one of two experts. If a token was lost ($M_i = 0$), it is sent to Expert-0, which is specialized in reconstructing data from context. If a token was received ($M_i = 1$), it is sent to Expert-1, which focuses on refining and preserving the received details. Because the routing is fixed by the known transmission status, this adds zero computational overhead and allows for efficient parallel processing.

![ermoe-ffn-mechanism](https://paper-assets.alphaxiv.org/figures-normalized/figures/2608.13245v1/FFN-2.png)
*{fig:ermoe-ffn-mechanism}: The External Routing Mixture-of-Experts (ERMoE) mechanism in the FFN layer, where the packet mask $M$ directly controls token routing.*

### ERMoE in Attention Layers (MHSA)
In the Multi-Head Self-Attention (MHSA) layers, the model uses a dense version of ERMoE. A lightweight convolutional layer processes the 2D packet mask to generate gating scores $\delta_0$ and $\delta_1$. These scores modulate the contribution of different linear experts when calculating the Query ($Q$), Key ($K$), and Value ($V$) matrices. This allows the attention mechanism to adapt its focus based on the spatial distribution of packet loss, essentially telling the model which neighboring tokens are reliable sources of information.

## Progressive Training Strategy

The model is trained in two distinct stages to ensure it learns both high-quality visual representation and robustness to communication errors:

1.  **Stage 1: Ideal Communication Training.** The system is trained on the perception task (e.g., image reconstruction) assuming perfect transmission. This helps the visual encoder and decoder establish a baseline for what high-quality features should look like.
2.  **Stage 2: Joint Training with Packet Loss.** The SoM-MTM module is activated, and the system is trained with simulated packet loss. The loss function $L$ combines the perception task loss $L_p$ with a feature regularization term:
$$L = L_p + \omega \cdot \text{MSE}(F_{ref}, F_{gt})$$
Here, $F_{gt}$ represents the "ground truth" features that would have been received under perfect conditions. This forces the SoM-MTM to refine the refined features $F_{ref}$ to match the ideal features as closely as possible.

## Performance and Generalization

The researchers evaluated SoM-MTM across various tasks, including image reconstruction, classification, and semantic segmentation. The experimental results highlight several strengths:

*   **Robustness to High Loss:** SoM-MTM consistently outperformed baselines (like Vanilla MAE or standard JSCC models) in reconstruction quality. Even when only 30% of packets were received, the model produced recognizable images with significantly higher PSNR (Peak Signal-to-Noise Ratio) than alternative methods.
*   **Zero-Shot Generalization:** A critical test for any AI-native communication system is how it handles data it hasn't seen before. SoM-MTM was evaluated on six untrained datasets (ranging from medical images to driving scenes) and different channel models. It showed an average 23% improvement in reconstruction quality over the next best method, demonstrating that the model learns general visual laws rather than just memorizing a specific dataset.
*   **Scalability:** Unlike many AI models that suffer from diminishing returns or instability as they grow larger, SoM-MTM scales effectively. As the number of layers increases, the performance continues to improve, providing a favorable trade-off between computational cost and perceptual accuracy.

## Universal Downstream Task Support

While reconstructing an image is a useful benchmark, many autonomous systems care more about specific tasks like "What object is this?" (classification) or "Where is the road?" (segmentation). SoM-MTM was tested for these end-to-end tasks by replacing the reconstruction decoder with task-specific heads. 

In image classification on the NWPU-RESISC45 dataset, the model maintained a Top-1 Accuracy of 80.9% across various loss rates, very close to the 82.1% achieved under perfect communication. In semantic segmentation, it achieved a mean Intersection over Union (mIOU) of 49.9%, compared to 50.4% under perfect conditions. These results suggest that high-level perceptual features are naturally redundant and that SoM-MTM can effectively recover the information necessary for decision-making even when the underlying communication link is highly unreliable.

## Implications for Future Networks

The SoM-MTM framework represents a shift toward "intelligent" data transmission. By moving the burden of error recovery from the communication protocol (retransmission) to the AI model (contextual reasoning), the system achieves:
1.  **Reduced Latency:** By eliminating the need for many retransmissions, the system provides faster updates for time-critical tasks.
2.  **Deployment Ease:** As a plug-and-play module, SoM-MTM can be added to existing Transformer-based perception pipelines without changing the fundamental architecture of the sensors or the communication hardware.
3.  **Broad Applicability:** The model is not tied to a specific perception task or a specific wireless frequency, making it a candidate for a universal enhancement in B5G/6G networks.

By treating packet loss as an inherent part of the environment rather than a failure to be corrected, SoM-MTM enables a more fluid and robust interaction between machines, laying the groundwork for truly AI-native communication systems.
