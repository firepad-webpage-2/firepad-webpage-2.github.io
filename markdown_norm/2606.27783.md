How does the brain keep track of where we are, which way we are facing, or the direction of our movements? In computational neuroscience, a leading framework for answering these questions is the Continuous Attractor Neural Network (CANN). These models describe how populations of neurons can represent continuous variables by forming a stable "bump" of activity that can move smoothly across the network in response to sensory input or internal velocity signals.

Despite their importance, CANN research has historically been fragmented. Researchers often rely on custom, lab-specific code that is difficult to share or compare. This lack of standardization creates high barriers for new researchers and complicates the validation of experimental data. The work by He et al. (2026) introduces the CANNs toolkit, a comprehensive, open-source ecosystem designed to unify modeling, high-performance simulation, and topological analysis of neural data.

## Principles of Continuous Attractor Neural Networks

At its core, a CANN is a recurrent neural network where the connections between neurons are determined by their relative positions in a feature space, such as physical location or orientation. This structure allows the network to support a family of stationary states, known as attractors, which form a continuous manifold.

The dynamics of a typical CANN are governed by the evolution of the synaptic input $U(\mathbf{x}, t)$ at position $\mathbf{x}$ and time $t$:

$$\tau \frac{\partial U(\mathbf{x}, t)}{\partial t} = -U(\mathbf{x}, t) + \int W(\mathbf{x}, \mathbf{x}') r(\mathbf{x}', t) d\mathbf{x}' + I_{ext}(\mathbf{x}, t)$$

In this equation, $\tau$ is the time constant of the system, $W(\mathbf{x}, \mathbf{x}')$ represents the recurrent weight between neurons at $\mathbf{x}$ and $\mathbf{x}'$, and $I_{ext}(\mathbf{x}, t)$ is the external input. The firing rate $r(\mathbf{x}, t)$ is typically determined through divisive normalization, which ensures the stability of the activity bump:

$$r(\mathbf{x}, t) = \frac{U(\mathbf{x}, t)^2}{1 + k \int U(\mathbf{x}', t)^2 d\mathbf{x}'}$$

Here, $k$ is a parameter controlling the strength of the global inhibition. Because the weights $W$ are usually translation-invariant (they only depend on the distance $|\mathbf{x} - \mathbf{x}'|$), the resulting activity bump can reside at any position in the network with equal energy, effectively "tracking" continuous variables like head direction (in a 1D ring network) or spatial position (in a 2D toroidal network).

## A Unified Software Ecosystem

The toolkit is divided into three integrated components, each serving a specific role in the research workflow.

### The `canns` Python Library
The core of the toolkit is the `canns` library, built on top of BrainPy and JAX. It provides a modular framework for defining neural models. The library includes pre-implemented versions of canonical models, such as the Wu–Amari–Wong (WAW) model, as well as more advanced variations incorporating spike-frequency adaptation (SFA) or theta-rhythmic modulations. By leveraging JAX, the library supports automatic differentiation and can run seamlessly on CPUs, GPUs, and TPUs.

### The `canns-lib` Rust Backend
To handle the computational bottlenecks inherent in large-scale simulations, the authors developed `canns-lib`, a backend written in Rust. Rust's memory safety and performance characteristics allow for highly optimized routines that are called transparently from Python. This is particularly significant for spatial navigation tasks, where an agent must move through an environment for millions of steps to generate realistic training data.

### The Attractor Structure Analyzer (ASA)
Perhaps the most distinctive feature of the toolkit is the Attractor Structure Analyzer (ASA). ASA is a graphical user interface (GUI) and a set of analysis pipelines designed to infer the underlying geometry of a neural population from its firing patterns. This allows researchers to take "point cloud" data—either from simulations or real experimental spike trains—and determine if the neurons are collectively representing a specific shape, like a circle or a torus.

## Performance and Computational Efficiency

Simulation speed is a critical factor in computational neuroscience, especially when exploring large parameter spaces or long-duration behaviors. The `canns-lib` backend provides a substantial performance boost over existing Python-based alternatives.

## Analyzing Neural Geometry with ASA

A central challenge in systems neuroscience is identifying the "state space" of a neural circuit. If a group of neurons represents a circular variable (like head direction), their joint activity should lie on a 1D ring manifold. If they represent grid-like spatial positions, they may lie on a 2D torus.

The ASA pipeline uses Topological Data Analysis (TDA) to identify these structures. The core method is persistent homology, which tracks the appearance and disappearance of topological features across different scales. These features are quantified by Betti numbers:
- $\beta_0$: Number of connected components.
- $\beta_1$: Number of 1D loops (circles).
- $\beta_2$: Number of 2D cavities (voids).

For example, a ring attractor is characterized by $\beta_0=1$ and $\beta_1=1$. A torus is more complex, requiring $\beta_0=1$, $\beta_1=2$, and $\beta_2=1$.

![asa-gui-for-tda](https://paper-assets.alphaxiv.org/figures-normalized/figures/2606.27783v1/asa_gui_tda_updated.png)
*{fig:asa-gui-for-tda}: The ASA interface displaying a persistent homology barcode. The long horizontal bars (persistent features) indicate the presence of a stable topological structure in the neural data.*

Beyond identifying the shape, the toolkit can decode "circular coordinates" ($\theta$) from the data. This allows researchers to map abstract topological features back to physical variables. If the decoded $\theta$ from a set of neurons closely matches the animal's actual head direction, it provides strong evidence that the circuit is functioning as a ring attractor.

## Empirical Validations and Reproducibility

The authors validated the toolkit by reproducing several well-known results from the literature and applying it to real neural recordings from the Medial Entorhinal Cortex (MEC).

### Simulated Attractors
The toolkit successfully recreates 1D ring attractors, 2D sheet attractors, and grid cell networks. For each, it provides a full suite of analysis tools, including energy landscape visualization and neural manifold projection. In simulations of grid cells, the toolkit confirmed the toroidal nature of the population activity, achieving high reconstruction accuracy ($R^2 > 0.99$).

### Real Neural Data
When applied to experimental data, ASA successfully detected ring-like signatures in head-direction cell populations and toroidal signatures in grid cell modules. The toolkit includes statistical "shuffle" tests to ensure that these topological features are not artifacts of noise. By comparing the lifetime of features in the real data against a null distribution, researchers can confidently identify significant attractor structures.

A particularly useful feature is the `CohoMap`, which visualizes how the decoded phases from the attractor manifold relate to the animal's position in the physical environment. In grid cell analysis, these maps reveal the periodic, multi-field nature of the cells when viewed in physical space, contrasted with their compact representation in the decoded "cohomology space."

## Impact on the Research Community

The introduction of the CANNs toolkit represents a move toward more transparent and reproducible science in computational neuroscience. By providing a common set of abstractions and high-performance tools, it addresses the technical debt that often accumulates in specialized research labs.

The toolkit is designed to be accessible to a wide audience. For computationalists, it offers a high-performance, JAX-compatible library for model development. For experimentalists, the ASA GUI provides a user-friendly way to apply sophisticated topological analyses to their recordings without needing to write complex code. Finally, for students, the extensive documentation and reproducible examples serve as an educational resource for learning the mathematical foundations of brain-inspired navigation models.

By unifying simulation and analysis within a single framework, the toolkit facilitates a tighter loop between theory and experiment, potentially accelerating the discovery of how neural circuits represent and compute continuous information.
