## Introduction to Volumetric Medical Image Compression

Lossless compression is a fundamental requirement in medical imaging. High-resolution scans from Computed Tomography (CT) and Magnetic Resonance Imaging (MRI) generate massive volumes of data that must be stored and transmitted without any loss of detail, as even minute pixel variations can lead to incorrect clinical diagnoses or compromised surgical planning. 

Currently, the field is divided into two primary approaches. Traditional methods like JPEG-XL, JPEG2000, and VVC are computationally efficient and fast but rely on handcrafted models that often fail to capture the complex, three-dimensional redundancies inherent in volumetric scans. Conversely, recent methods based on Deep Neural Networks (DNNs) achieve superior compression ratios by learning data distributions from large datasets. However, these DNN-based models require expensive GPU hardware, suffer from slow decoding speeds, and often struggle to generalize to different scanners or high bit-depth data (e.g., 16-bit images).

The research introduces the Tri-plane Context Tree (TCT) method, which aims to bridge the gap between these two paradigms. TCT is a non-DNN approach that performs "instance-level learning," meaning it creates a custom statistical model for every individual image it compresses. By combining an adaptive tree structure with efficient 2D projections of 3D data, TCT achieves compression performance comparable to state-of-the-art deep learning models while maintaining the speed and low hardware requirements of traditional codecs.

## The Tri-plane Context Representation

A major challenge in volumetric compression is modeling 3D context efficiently. While a pixel's value is highly correlated with its neighbors in all three dimensions, modeling these dependencies directly in 3D is computationally expensive. The TCT method addresses this by using a tri-plane context representation.

Instead of looking at a 3D block of neighbors, the method projects the already-encoded pixels surrounding the current pixel onto three orthogonal 2D planes: the $x-y$ (axial), $y-z$ (sagittal), and $x-z$ (coronal) planes. This decomposition allows the system to capture 3D spatial information while only performing 2D modeling operations, which significantly reduces the computational complexity from cubic to quadratic.

This representation is supported by a set of 12 features, denoted as $f_i$, extracted for each pixel to describe its local environment:
*   **Gradient-2D Features (6 features):** These describe edges and textures on the high-resolution $x-y$ plane.
*   **Gradient-3D Features (4 features):** These aggregate gradients from the $y-z$ and $x-z$ planes to capture inter-slice relationships.
*   **Prediction Value Features (2 features):** These provide baseline estimates from simple predictors to help the model distinguish different anatomical structures.

## Tri-plane Context Tree (TCT) Architecture

The core of the methodology is the Tri-plane Context Tree, an adaptive binary tree that partitions the pixel space into distinct "contexts." For each pixel, the tree is traversed from the root to a leaf node based on the extracted feature vector $f_i$. Each internal node in the tree contains a feature index and a threshold value used to decide which branch to follow.

![architecture-of-the-tri-plane-context-tree-learning-and-coding-framework](https://paper-assets.alphaxiv.org/figures-normalized/figures/2608.13897v1/figures/algorithm8.png)

When a pixel reaches a leaf node, it is assigned a specific "context." Each context $C_j$ is associated with:
1.  **A specialized predictor:** Chosen from three candidates (Median-2D, Median-3D, or Blending-3D) to estimate the pixel value.
2.  **Probability models (histograms):** Used for entropy coding the prediction residual.

By learning this tree specifically for the input image, the method adapts to the local structural characteristics of that scan. For example, the tree might separate smooth background regions from complex organ boundaries, applying different statistical models to each to maximize compression efficiency.

## Adaptive Prediction and Residual Modeling

To handle the wide variety of anatomical structures, TCT utilizes three different predictors. The model dynamically selects the most accurate one for each context:

1.  **Median-2D Predictor:** A standard 2D predictor using neighbors within the current slice.
2.  **Median-3D Predictor:** An extension that applies the median prediction across all three orthogonal planes.
3.  **Blending-3D Predictor:** A sophisticated scheme that combines ten sub-predictors from the three context planes, weighting them based on local residuals.

The difference between the actual pixel value and the predicted value is the prediction residual $r_i$. In high bit-depth medical images, $r_i$ can span a wide range. To optimize entropy coding, the method converts $r_i$ into a "quadruple representation":
*   $zbit$: A flag indicating if the residual is zero.
*   $sbit$: The sign of the residual.
*   $msb$: The most significant bits of $|r_i| - 1$, capturing the magnitude.
*   $lsb$: The remaining least significant bits.

This breakdown reduces the complexity of the probability distributions that the entropy coder must handle, allowing for more efficient compression of the most frequent values.

## Performance and Practical Efficiency

The TCT method was evaluated across multiple datasets, including CT and MRI scans with both 8-bit and 16-bit depths.

### Compression Performance
The method consistently outperforms traditional standards like JPEG-XL, VVC, and JPEG2000. On 16-bit datasets like Chaos and MosMedData, it matches or exceeds the performance of state-of-the-art DNN-based methods. For example, on the Chaos dataset, TCT achieved 4.27 bits per pixel (BPP), whereas the DNN-based BCM-Net achieved 6.49 BPP when tested on data outside its training domain.

### Speed and Hardware
The most significant practical advantage is decoding speed. Because TCT does not rely on heavy neural network architectures, it can decode images using a standard CPU at speeds comparable to traditional codecs. Testing showed that TCT is between 40 to 145 times faster at decoding than contemporary DNN-based lossless compressors. This speed is critical for clinical workflows where doctors need to scroll through 3D volumes in real-time.

Furthermore, because the model is learned from the image itself (using a sampled subset of pixels for speed), it requires no pre-training on external datasets. This makes it inherently robust to "out-of-domain" data, a common failure point for deep learning models.

## Conclusion

The Tri-plane Context Tree method offers a practical and high-performance solution for the lossless compression of volumetric medical images. By using instance-level statistical learning and an adaptive tree structure, it captures the multi-dimensional redundancies of 3D scans more effectively than rigid traditional methods. Simultaneously, it avoids the high computational costs, slow speeds, and generalization issues of deep learning models. Its ability to provide state-of-the-art compression ratios with fast, CPU-only decoding makes it a highly viable candidate for integration into modern medical imaging systems and clinical diagnostic workflows.
